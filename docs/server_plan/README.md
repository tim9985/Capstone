## 먼저 알아둘 결정 (2026-09-13)

- **자동 자세 판별(쓰러짐 분류)은 하지 않는다.** 사람 1클래스 탐지(누운 사람·부분 가림 포함), 쓰러짐 여부는 운영자 판단 → `참고/결정 - 자세 판별 제외.md`
- 비전 우선순위: **미탐 → 오탐 → 상의 색상 비교(12색) → 좌표**
- 인상착의(상의 색상) 비교 · 개별 대상 추적은 **구현 확정**. 정확도 · 추적 유지율 수치 목표는 두지 않는다
- 서버 E2~E8 은 중단 상태 → 이 계획의 **S1 데이터 재생성**부터 시작

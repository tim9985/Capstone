## 부탁드릴 것 (sudo 단계)

1. 이미지 한 층 빌드 · compose 의 vision 에 `image:` 한 줄 · `sync-workspace.sh` → `stack.sh up -d vision`
2. 컨테이너 안 인수 검증 한 번 (`README.md` 5번 명령) — 통과 기준 AP50 0.5927 ± 0.003

## 같이 정할 것

1. **촬영 시각 · 자세 sidecar 형식** — 초안은 `app/vision_core/telemetry.py` 머리말 (telemetry.jsonl · frames.jsonl) · Pi · 서버 시계 동기 · RTSP 를 거친 PTS 가 Pi 쪽 PTS 와 같은지
2. **DB 쓰는 쪽** — vision 이 직접 쓸지 (DB 계정 필요) · API 가 `candidates.jsonl` 을 읽어 넣을지 · 테이블은 관제 담당 ERD 기준
3. **GPU 메모리** — 학습과 같은 GPU (vision 2~3 GB) · 시연 · 측정 시간에는 학습을 멈추는 규칙

## 남은 가능성 (하드웨어)

1. **전원 공급의 순간 피크** — 3090 은 밀리초 단위로 평균의 약 2배 전력을 끌어간다. `nvidia-smi -pl` 은 평균만 제한하므로 이걸 못 막는다.
2. **PCIe 연결** — Gen4 신호 품질 · 슬롯 접촉 · 라이저 케이블. `pci=noaer` 부팅 옵션 때문에 PCIe 오류(AER)가 로그에 남지 않아 확인이 안 된다.
3. **GPU 카드 자체 결함**

## 점검 요청 (우선순위 순)

1. 파워서플라이 용량 확인 (RTX 3090 + i9-11900 기준 850 W 이상 권장) · GPU 보조전원 8핀 2개를 **서로 다른 케이블 2가닥**으로 연결했는지 (한 케이블에서 분기하면 순간 피크에 취약)
2. GPU 재장착 · 라이저 케이블 사용 여부 · 슬롯 상태
3. BIOS 에서 GPU 슬롯을 **PCIe Gen3 로 고정** (Gen4 신호 불안정 대응. 학습 속도 영향 작음)
4. 진단을 위해 `pci=noaer` 를 빼고 부팅 → 부하 중 PCIe 오류가 쌓이는지 확인
5. 가능하면 다른 슬롯 · 다른 파워서플라이 · 다른 GPU 로 교차 확인

## 4. 실행 방식 제안 — GPU 장애를 전제로

1. **`run_queue.sh` 를 재개 가능하게**
   - 대기열 파일 한 줄 = 실험 이름 + 명령.
   - 끝난 실험(완료 표시 · `best.pt` 백업 있음)은 건너뛴다.
   - `runs_person/<이름>/weights/last.pt` 가 있으면 `yolo train resume model=…/last.pt`, 없으면 새로 시작한다.
2. **autoheal 과 연결**
   - 지금 `autoheal/job.conf` 는 실험 하나(M1) 기준이다.
   - `JOB_SCRIPT=run_queue.sh` 로 바꾸고, 완료 판정을 "대기열 완료 표시 파일"로 바꾼다.
3. 실험이 끝날 때마다 `results.csv` · `best.pt` · `args.yaml` 백업 + `SERVER_PROGRESS.md` 한 줄.
4. 공통 환경: `MPLBACKEND=Agg` (화면 없는 서버에서 최종 검증 그림이 죽는다) · `yolo` 절대경로 · `batch` 명시 · `save_period 10`.
5. 진행 확인: `python train_status.py` (서버용으로 고침 · 이어 학습 · 시간 제한 반영).

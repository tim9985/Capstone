## 1. 과제와 운용 조건

「자율 정찰 드론 관제 시스템」 비전 파트 — 고령 인구 밀집 농촌·산지에서 **쓰러진 사람을 포함해 사람을 찾아**
화면 좌표를 실좌표로 바꿔 관제 지도에 신고한다. 팀: 이시원(관제) · 서성훈(비행) · 정서인(비전).

| 항목 | 값 |
|---|---|
| 카메라 | IMX415 + 5.5 mm · 수평 화각 **54.0°** (렌즈 실측 전 — 4.8 mm·60.5° 도 대비) · **1920×1080** |
| 마운트 | 무짐벌 · **하향 90° 현재안** (요구명세서는 "하향 30~90° 지원" — 운용 각도 미정) |
| 고도 | 16 ~ 30 m · 폭 W = 2·고도·tan27° · GSD = W/1920 |
| 16 m (1920 원본) | 서 있는 사람(위에서 본 어깨폭) **59 px** · 누운 사람 **200 px** |
| 30 m (1920 원본) | 서 있는 사람 **31 px** · 누운 사람 **107 px** |
| **모델 입력 1280** | 위 수치 × 0.667 → 사람 약 **18 ~ 133 px** (계획의 기준 입력) |
| 분석 입력 (SRS v1.6 NFR-P02) | 1920×1080 수신 · 모델 입력 크기는 별도 기록 (NFR-V01) |

**모든 판단은 이 표 기준이다.** 하향이라 영상에 "위쪽"이 없다 → 회전 180° · 상하반전 증강이 맞다.

## 4. ⚠ 서버 작업에 바로 해당하는 것

1. **NOMAD 검증셋이 노트북과 다르다 → 노트북 수치와 직접 비교 불가.** (2026-09-12 양쪽 확인)
   `nomad_prep.py` 는 실행(배치)마다 seed 42 로 그 배치 배우만 섞어 20% 를 val 로 뽑는다.

   | 배치 | 노트북 (`stage1_all`) | 서버 (E1~E8) |
   |---|---|---|
   | 001~010 | val 004 · 008 | val 004 · 008 |
   | 011~020 | val 014 · 018 | val 014 · 018 |
   | 021~030 | **`--all-train` → val 없음** (024 · 028 도 학습) | val **024 · 028** |
   | 선정 목록 31번 이후 30명 | 사용 안 함 | val 048 · 059 · 071 · 079 · 088 · 094 |

   - **공정한 공통 홀드아웃 = 서버 val 에서 024 · 028 을 뺀 10명**
     `004 · 008 · 014 · 018 · 048 · 059 · 071 · 079 · 088 · 094`. 최종 비교는 이것으로 → `obsidian/11 서버 학습 계획/7 평가 프로토콜.md`
2. **조기 종료는 mAP50 이 아니라 fitness = 0.1·mAP50 + 0.9·mAP50-95** 로 판단된다.
3. **초반 2~4 에폭 하락은 warmup 때문이다.** 그걸로 끊지 말 것.
4. **WiSARD val 앞쪽 291장은 사람이 없는 음성 표본이다.** `--limit` 으로 앞에서부터 자르면 재현율이 비어 나온다.
5. **소표본으로 결론 내지 말 것.** 70장 진단에서 "WiSARD 0.887→0.883 유지"라 했다가 전체로 재니 0.804 였다.
6. **학습 imgsz 는 1280 까지만.** 크롭 원본이 1280×720 이다. 추론만 1600·1920 으로 키워 보는 건 계획 S5.
7. **옛 전처리 목표 94 px 는 틀린 가정이다** (화각 60° · 20 m · 키 1.7 m). 우리 카메라 기준 입력 1280 사람은 18~133 px →
   계획은 **로그 균등 22~120 px + 학습 중 `scale 0.3`** → `obsidian/11 서버 학습 계획/4 전처리 - 크기 정규화와 지터.md`
8. **학습 데이터 대부분이 비스듬한 시점이다.** WiSARD 는 비행마다 각도가 다르다(1월 Baker 는 측면) → 비행별 각도 태그부터 → `obsidian/11 서버 학습 계획/3 데이터 구성.md`
9. **Okutama 는 평가 전용이다** (배우 수가 적다). 서버에 없으면 노트북에서 복사(9.6 GB).
10. 가중치 출처가 궁금하면 `WEIGHTS.md`. 노트북 가중치는 **`--resume` 금지**(Windows 경로가 박혀 있음) — 쓰려면 `--weights`.

   - **공정한 공통 홀드아웃 = 서버 val 에서 024 · 028 을 뺀 10명**

3. **초반 2~4 에폭 하락은 warmup 때문이다.** 그걸로 끊지 말 것.
4. **WiSARD val 앞쪽 291장은 사람이 없는 음성 표본이다.** `--limit` 으로 앞에서부터 자르면 재현율이 비어 나온다.

### 2026-09-17 ~ 20 에 새로 확인한 것

11. **재현율 단독으로 모델을 비교하지 말 것 — AP 와 짝으로 본다.** 두 번 당했다.
    · 93°·40 m·서 있음 칸에서 11l 이 **재현율@0.15 0.1956→0.2142 (+1.9 %p · 상대 +9.5 %)** 인데
      같은 칸 **AP50 은 0.1151→0.0926 (−2.2 %p · 상대 −19.5 %)** 였다 (저신뢰 박스 남발)
    · 추론 입력 스윕에서 재현율@0.15 과 오탐(건/프레임)이 **같은 방향**으로 움직여 고정 임계값 비교가 교란됐다
12. **val mAP50 으로 모델을 고르면 실전과 반대로 간다.** 11l 이 **val mAP50 상대 +4.9 %** 로 이겼으나
    가림 지형 18칸 **전부** 재현율@0.15 열세였다. 원인은 11l 이 오탐(건/프레임)을 **상대 19 %** 줄여
    AP 가 보상한 것 — 우리 우선순위는 미탐이고 오탐은 이미 NFR-V06 을 통과한 상태다.
    → **운용 크기 구간(18~50 px) 재현율@0.15 을 1차, 같은 구간 AP50 을 2차 기준으로 쓴다**
13. **`close_mosaic` 은 우리 조건에서 해롭다.** 해제 직전(25에폭) → 완주(30에폭) **val mAP50**:
    11s 0.4224→0.3987(**−0.024 · 상대 −5.6 %**) · 11l L1 0.4411→0.4254(**−0.016 · −3.6 %**) ·
    11l L2 0.4769→0.4693(**−0.008 · −1.6 %**). 모델 3종 · 데이터 2종에서 일관되게 떨어졌고
    회복이 없었다. **다음 학습부터 `close_mosaic 0`**
    (09-20 정정 — 예전 "L1 −9.9 %" 는 20→30에폭 값이었다)
14. **추론 방식이 아키텍처보다 큰 레버다.** 같은 가중치 · 모두 **서 있는 38 px 재현율@conf 0.15**:
    · 해상도 1280 → 1920: 0.283 → 0.3444 (**+6.1 %p · 상대 +21.6 %**)
    · 타일 4×(1280×720): 0.3444 → 0.3729 (**+2.9 %p · 상대 +8.3 %**) (FP16 39.7 ms · NFR-V01 초과)
    · 반면 모델 확대 11m → 11l 은 운용 구간에서 **상대 −3~−8 %**, 학습 데이터 +64 %(AI-Hub)는 11m 을 **못 넘었다**
    → P2 헤드 · 모델 교체보다 **추론 파이프라인(TensorRT · 타일) 최적화가 먼저**
15. **FP16 은 공짜다.** 재현율@0.15 차이 **±0.25 %p 이내** (400장 중 1장 수준), 시간 **상대 −35~39 %**.
    FP32 로는 11m 조차 1920 입력에서 32.3 ms 로 NFR-V01 을 넘는다. **추론은 항상 FP16**
16. **AI-Hub 182 는 학습용이지 검증용이 아니다.** 가림 없는 단독 피사체라 같은 30 px 에서
    **재현율@0.15 이 0.86 vs NOMAD·WiSARD 0.33**. 장소 분리 val 에서 AP50 0.9950 · 재현율@0.15 **1.0000** 이 나온다 —
    기준 충족이 아니라 **시험셋이 쉽다는 증거**다
17. **`pgrep -f` · `pkill -f` 는 자기 셸을 잡는다 — 세 번 당했다 (09-18 · 09-21 ×2).**
    괄호 idiom(`'[m]ine_neg'`)만으로는 부족하다. **같은 명령줄의 heredoc 본문에 스크립트 이름이
    평문으로 들어 있으면 그것까지 매칭**된다 (`p=Path("xxx.py")` 같은 줄). exit 144 로 죽는다.
    · 파일 편집은 heredoc 대신 **별도 스크립트 파일**로 빼서 실행한다
    · 프로세스 종료는 **PID 로** 한다 — 이름 패턴은 확인용으로만, 그것도 평문이 같이 없을 때만
18. **서버는 UTC 다 — `date` 출력에 "KST" 를 붙이지 말 것 (09-21).**
    `date '+%F %T'` 는 **UTC** 를 뱉는다. 여기에 "KST" 를 리터럴로 붙여 적어
    학습 완주 시각을 **9시간 틀리게** 보고했다 ("오늘 18:00" → 실제 다음날 03:00).
    · 스크립트·보고 모두 **`TZ=Asia/Seoul date '+%F %T'`** 를 쓴다
    · 옛 스크립트들은 `%Z` 를 붙여 "UTC" 라고 정직하게 찍고 있었다 — 그 방식이 안전하다
    · 볼트 기록은 **KST 기준**으로 통일한다 (팀이 읽는 시각이다)
19. **시험셋 칸은 사람 px 로 정의된다.** `det_fullframe` 의 s38 = 38 px · l128 = 128 px.
    거기 붙은 "54° · 25 m · 하향 90°" 표기는 **옛 0.5 m 가정**으로 계산한 것이다 (실측 0.81 m).
    **마운트각은 어느 시험셋도 모형화하지 않았다** — 크기만 재현한다

## 6. 막다른 길 — 다시 하지 말 것

- **마스크 기하(박스 종횡비·PCA 축비)로 fallen/person 구분** — AUC 0.342 / 0.387, 오히려 반대 방향
- **200 px 로 키워 자세 분류** (Okutama 6차) — 해상도 가설 기각
- **학습률만 낮추기** — 동결 없이 lr 만 낮춰서는 망각을 못 막는다

- **ForestPersons(ETRI)** — 지상 1.5~2 m 시점
- **모델 용량 확대로 소형 객체 해결** — 11m → 11l 은 운용 구간에서 −3~−8 %
- **네이티브(1920) 초과 업스케일 추론** — 2560·3200 은 시간 3.5~5배에 이득 불확실, 큰 대상은 명확히 손해
- **2×(1280×1080) 타일** — 단일 1920 과 재현율·시간이 같다 (겹침이 없으면 이득도 없다)
- **`translate` 0.15 → 0.30 으로 타일 가장자리 보정** (09-21) — 가장자리/중앙 격차는 −23.6 % → −6.5 % 로 줄었지만
  **중앙이 무너져서** 줄었다. 서 있는 38 px 가중 평균 재현율@0.15 **0.2737 → 0.2248 (−4.9 %p)**.
  누운 128 px 은 +0.6 %p 로 무변화 — 작은 대상만 잘려 나간다. **0.20~0.25 재시도도 권하지 않는다**

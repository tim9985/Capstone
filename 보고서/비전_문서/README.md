## 어떤 순서로 읽으면 되나

**팀원에게 공유한다면** 01 하나면 된다. 시스템이 무엇을 보장하고 무엇을 보장하지
않는지가 다 들어 있다.

**비전 작업을 이어받는다면** 03(원리) → 04(절차) 순서로 읽고, 02 에서 남은 과제를
확인한다.

**자세 판별을 다시 시도한다면** 05 를 먼저 본다. 여섯 차례 실패의 조건과
선행 성공 사례의 조건이 무엇이 달랐는지 정리돼 있다.

## 갱신 방법

`.html` 파일과 웹 링크는 같은 내용이다. 웹 쪽을 고치면 파일도 다시 받아
덮어써야 두 곳이 어긋나지 않는다.

각 문서 하단에 근거 자료 목록이 있으니, 수치를 바꿀 때는 그 출처부터 확인한다.

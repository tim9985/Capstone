# 1. 개요

## 1.1 시스템의 목표

- 고령 인구가 많은 농촌·산지에서 **드론이 자율 정찰하며 사람(쓰러진 사람 포함)을 찾는다**
- 탐지한 사람의 **화면 좌표를 실좌표로 바꿔 관제 지도에 표시**한다
- 운영자는 스냅샷을 보고 대응 여부를 **직접 판단**한다 — 시스템은 후보만 제시

| 목표 | 설계상 의미 |
|---|---|
| 자율 정찰 | 관측 완료도를 계산해 **미관측 영역을 스스로 고른다** (UC-08xx) |
| 사람 탐지 | 누운 사람·부분 가림 포함 **1클래스(person)** · 자세 자동 분류 없음 |
| 좌표 신고 | 박스 아래 변(발끝) 광선–지면 교차로 실좌표 산정 (NFR-V04) |
| 운영자 판단 | 후보 제시 → 운영자 판정 (UC-0705) |

## 1.2 소프트웨어의 주요 기능

| 구분 | 기능 | 대응 UC |
|---|---|---|
| 관제 | 로그인·권한·제어권, 지도·레이어, 임무구역 지정, 알림 | UC-01xx · 03xx · 04xx · 11xx |
| 비행 | 기체 상태·통신, 탐색 후보 생성·관측지점 선택, 명령 검증·전달, 안전·장애 | UC-02xx · 05xx · 09xx · 10xx |

# 2. 파일 구조 또는 데이터베이스 설계

## 2.1 주요 엔티티

```
임무(Mission) 1──N 관측지점(Waypoint) 1──N 관측기록(Observation)
     │
     ├──N 프레임(Frame) 1──N 탐지(Detection) N──1 후보(Candidate) 1──N 스냅샷(Snapshot)
     ├──N 명령(Command) 1──N 명령응답(CommandAck)
     ├──N 알림(Alert)
     └──1 임무설정(MissionConfig) — 구역 · 고도 · 마운트각 · 렌즈 · 복귀조건 · 실행버전
```

## 2.2 핵심 테이블 `[잠정]`

| 테이블 | 주요 컬럼 | 설계 근거 |
|---|---|---|
| `mission` | id, 구역, 고도, 속도, 복귀조건, **실행버전**, 시작/종료시각, 종료사유 | UC-1201 — 편집본과 실행본 구분 |
| `mission_config` | mission_id, **렌즈(f·화각)**, **마운트각**, 탐지 임계값, 모델 버전 | 좌표 산정·재현에 필요 |
| `frame` | id, mission_id, 프레임식별자, 촬영시각(원본/추정), 기체 자세·위치, **짐벌각**, 추정방식·불확실성 | UC-0602 — 시각이 추정이면 남긴다 |
| `detection` | id, frame_id, bbox, 신뢰도, 클래스(person) | UC-0701 |
| `candidate` | id, mission_id, 대표좌표, **좌표유효/보류**, 상의색상 1·2순위, 운영자판정 | UC-0703·0706·0708 |
| `snapshot` | id, candidate_id, 파일경로, 촬영시각 | UC-0607 |
| `observation` | id, waypoint_id, 가시영역 폴리곤, 품질등급, 가림여부 | UC-0802 |
| `command` | id, mission_id, 종류, **제어세대**, 유효기간, 검증결과, 거부사유 | UC-0901·0902 |

- 좌표를 못 구한 후보도 **버리지 않고 `좌표보류`로 저장** (UC-1204)
- 짐벌각은 **프레임마다** 기록 — 비행 중 바뀌므로 임무설정 값만으로는 좌표를 못 푼다

## 4.1 Deployment Diagram (시스템 운용도)

```
┌──────────────────┐  5GHz 200mW    ┌──────────────────┐  인터넷   ┌──────────────────┐

│ IMX415 + 88° 렌즈│                │ 중계 · 순환 기록  │           │ vision · core    │
│ GM3 V2 짐벌      │                └──────────────────┘           └────────┬─────────┘
└──────────────────┘                                                        │ HTTPS·WebSocket
                                                                   ┌────────▼─────────┐
```

## 4.4 Design Classes (클래스 설계)

### vision 클래스 `[확정]`

| 클래스 | 책임 | 주요 속성 | 주요 연산 |
|---|---|---|---|
| `FrameIngestor` | 프레임 수신·시각 동기·대기열 제한 | 대기열 길이, 허용 지연 | `accept(frame)` · `dropStale()` |
| `TileSplitter` | 1920×1080 → 1280×720 타일 4장 (겹침 50 %) | 타일 크기, 겹침 | `split(frame) → Tile[]` |
| `PersonDetector` | TensorRT FP16 엔진 추론 | 엔진 경로, conf 0.15 | `detect(Tile[]) → Detection[]` |
| `DetectionMerger` | 타일 → 프레임 좌표 · NMS(IoU 0.6) | IoU 임계 | `merge(Detection[])` |
| `GeoResolver` | 발끝–지면 교차 좌표 | CameraModel, 지면 고도 | `toWorld(bbox, pose, gimbal, h) → LatLon \| PENDING` |
| `ColorProfiler` | 상의 Lab 12색 1·2순위 | 색상표 | `profile(crop) → Color[2]` |
| `SnapshotWriter` | 스냅샷 저장·후보 연결 | 저장 경로 | `save(frame, detection)` |
| `CandidateRegistry` | 후보 생성·병합·판정 상태 | 병합 거리 | `upsert(detection, latlon, color)` |
| `common.CameraModel` | 렌즈·짐벌 파라미터 | f, 화각, 마운트각 | `ray(u, v) → 3D 벡터` |

### 사람 탐지 (`PersonDetector` · `TileSplitter` · `DetectionMerger`) `[확정]`

| 항목 | 값 | 근거 |
|---|---|---|
| 모델 | YOLO11m · 1클래스(person) · COCO 사전학습 | 자세 분류는 도메인 이전 실패로 제외 (SARD 0.974 → Okutama 0.091) |
| 모델 파일 | 같은 설정 반복 학습 2~3개의 **가중치 평균 1개** | 추론 비용 그대로 · 처음 보는 장소에서 +1.6~2.2 %p (test_obl) |
| 입력 | 1280×720 타일 4장 · 겹침 50 % | 단일 1920 입력 대비 AP50 **+3.0 %p** (95 % +1.3~+5.6 · test_v2) |
| 정밀도 | FP16 | FP32 대비 AP50 −0.04 %p · 시간 −35 % |
| 실행 | TensorRT 엔진 `imgsz=[736,1280]` | 정수 하나로 주면 정사각 엔진이 돼 이점이 사라진다 |
| 추론 시간 | **18.5 ms** (RTX 3090) | NFR-V01 여유 38 % |
| 임계값 | conf 0.15 · NMS IoU 0.6 | F2 최적 0.075~0.125 와 차이 ≤0.008 · 최종 모델로 09-29 재조정 |

### 학습 설계 (60° 운용 기준) `[잠정]`

| 항목 | 값 |
|---|---|
| 학습 데이터 | 비스듬 시점 **≈50 %** (Unicamp-UAV · VisDrone 비스듬 · NII-CU 45°) + 수직·야생 (AI-Hub 182 · WiSARD · SARD · HERIDAL) · 장소당 상한 3,000장 |

### 좌표 산정 (`GeoResolver`) `[확정]`

- 박스 **아래 변(발끝)** 을 지면 접촉점으로 본다 — 몸 중심은 지면 위라 더 멀게 나온다

```
f = (W/2) / tan(HFOV/2)                 88° 렌즈: f = 1,141 px
φ = θ + atan((v − H/2) / f)             θ = 마운트각 (90° = 수직 하향)
수평거리 d = h / tan φ
사선거리 R = h / sin φ
```

- 가로 방향은 3차원 광선을 **기체 자세(roll·pitch·yaw) + 짐벌각으로 회전**한 뒤 지면과 교차 — 각도를 더하기만 하면 기울었을 때 틀린다

**오차 예산** (고도 25 m · 화면 중앙 · GPS 3 m · 짐벌각 2° · 고도 3 m · 기복 5 m)

| 마운트각 | 합성 오차 | NFR-V04 (10~15 m) |
|---:|---:|---|
| 90° | 3.1 m | ✅ |
| **60° (기본)** | **4.7 m** | ✅ |
| 45° | 6.8 m | ✅ |
| 30° | 11.1 m | ⚠️ 경계 |

- 오차를 좌우하는 것은 짐벌각이 아니라 **지형 기복** (30° 에서 5 m 기복 → 8.7 m)
- 발끝이 가려지면 거리를 **짧게** 잡으므로 `좌표보류` 처리

### 관측 완료도 `[잠정]` — 비행 담당과 공동

- 렌즈 f · 마운트각 · 고도로 촬영 범위(60° · 30 m: 앞 2.4~43.4 m) 계산
- 품질 기준을 통과한 가시 영역만 누적
- 품질 부족·가림·운용 제한은 **분모에서 빼되 사유를 남긴다** (UC-0804)

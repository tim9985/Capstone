# 1. 개요

## 1.1 시스템의 목표

고령 인구가 밀집한 농촌·산지에서 **드론이 자율 정찰하며 쓰러진 사람을 포함해 사람을 찾아**,
화면 좌표를 실좌표로 변환해 관제 지도에 신고한다. 운영자는 스냅샷으로 대응 여부를 판단한다.

| 목표 | 설계상 의미 |
|---|---|
| 자율 정찰 | 관측 완료도를 계산해 **미관측 영역을 스스로 선택**한다 (UC-08xx) |
| 사람 탐지 | 누운 사람·부분 가림 포함 **1클래스** 탐지. 자세 자동 분류는 하지 않는다 |
| 좌표 신고 | 발끝–지면 교차로 실좌표 산정 (NFR-V04) |
| 운영자 판단 | 시스템은 **후보를 제시**하고 판정은 운영자가 한다 (UC-0705) |

## 1.2 소프트웨어의 주요 기능

| 구분 | 기능 | 대응 UC |
|---|---|---|
| 관제 | 로그인·권한·제어권, 지도·레이어, 임무구역 지정, 알림 | UC-01xx · 03xx · 04xx · 11xx |
| 비행 | 기체 상태·통신, 탐색 후보 생성·관측지점 선택, 명령 검증·전달, 안전·장애 | UC-02xx · 05xx · 09xx · 10xx |
| **영상** | **영상 수신·시각 동기, 사람 탐지, 스냅샷, 상의 색상 비교, 좌표 산정** | **UC-06xx · 07xx** |
| 공통 | 관측 완료도, 임무 기록·조회·내보내기 | UC-08xx · 12xx |

## 4.2 영상 분석(vision) 클래스 설계 `[확정]`

| 클래스 | 책임 | 주요 연산 |
|---|---|---|
| `FrameIngestor` | 프레임 수신·시각 동기·대기열 제한 | `accept(frame)` · `dropStale()` |
| `TileSplitter` | 1920×1080 → 1280×720 타일 4장 (겹침 50 %) | `split(frame) → Tile[]` |
| `PersonDetector` | TensorRT FP16 엔진 추론 | `detect(Tile[]) → Detection[]` |

| `GeoResolver` | 발끝–지면 교차 좌표 산정 | `toWorld(bbox, pose, h) → LatLon \| PENDING` |

| `SnapshotWriter` | 스냅샷 저장·후보 연결 | `save(frame, detection)` |

### 처리 흐름

```
FrameIngestor → TileSplitter → PersonDetector → DetectionMerger
                                                      ├→ GeoResolver   → Candidate
                                                      ├→ ColorProfiler → Candidate
                                                      └→ SnapshotWriter
```

## 4.3 주요 알고리즘

### 4.3.1 사람 탐지 `[확정]`

| 항목 | 값 | 근거 |
|---|---|---|
| 모델 | YOLO11m · **1클래스(person)** | 자세 분류는 도메인 이전 실패로 제외 (SARD 0.974 → Okutama 0.091) |
| 입력 | 1280×720 타일 4장 · 겹침 50 % | 단일 1920 대비 **+2.9 %p** |
| 정밀도 | **FP16** | FP32 대비 정확도 차 −0.04 %p · 시간 −35 % |
| 실행 | TensorRT 엔진 `imgsz=[736,1280]` | **정수로 주면 정사각 엔진이 빌드돼 이점이 사라진다** |
| 임계값 | conf **0.15** | F2 최적 0.075~0.125와 차이 ≤0.008 |
| 병합 | NMS IoU 0.6 | |

### 4.3.2 좌표 산정 `[확정]`

박스 **아래 변(발끝)** 을 지면 접촉점으로 보고 광선–지면 교차로 푼다.
몸 중심은 지면 위에 있어 광선이 더 멀리 떨어진다.

```
f = (W/2) / tan(HFOV/2)
φ = θ + atan((v − H/2) / f)        θ = 마운트각 (90° = 수직 하향)
수평거리 d = h / tan φ
사선거리 R = h / sin φ
```

가로 방향은 3차원 광선 벡터를 **기체 자세(roll·pitch·yaw)로 회전**시킨 뒤 지면과 교차시킨다.
각도를 단순 가산하면 기울어진 상태에서 틀린다.

**오차 예산** (고도 25 m · 화각 75° · GPS 3 m · 짐벌각 2° · 고도오차 3 m · 기복 5 m)

| 마운트각 | 합성 오차 | NFR-V04 (10~15 m) |
|---:|---:|---|
| **90°** | **3.1 m** | ✅ |
| 60° | 4.7 m | ✅ |
| 45° | 6.8 m | ✅ |
| 30° | 11.1 m | ⚠️ 경계 |

> 지배 요인은 짐벌각이 아니라 **지형 기복**이다 (30°에서 5 m 기복 → 8.7 m).
> 가림으로 발끝이 안 보이면 거리를 **과소평가**하므로 `좌표보류`로 처리한다.

### 4.3.3 관측 완료도 `[잠정]` — 비행 담당과 공동

카메라 화각·장착각·고도로 촬영 범위를 계산하고, 품질 기준을 통과한 가시 영역만 누적한다.
품질 부족·가림·운용 제한은 **분모에서 제외하되 사유를 남긴다** (UC-0804).

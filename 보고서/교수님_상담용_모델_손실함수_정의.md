# 모델 정의 · 손실함수 정의 · Feed Forward · 손실값 계산

> 자율 정찰 드론 관제 시스템 · 사람 탐지 · 2026-09-19
> 아래 수치는 학습된 `fov_11m_1280_all` (yolo11m · 1클래스) 로 실제 실행해 얻은 값이다.

## 교재 예제와의 대응

| 교재 (선형 회귀) | 우리 (사람 탐지) |
|---|---|
| `t_u` — 입력 온도 | `x` — 1280×720 RGB 크롭 |
| `w, b` — 파라미터 2개 | `θ` — 가중치 **20,053,779개** |
| `model(t_u,w,b) = w*t_u + b` | `model(x, θ)` — CNN (backbone → neck → head) |
| `t_p` — 예측 스칼라 | `(boxes, scores)` — 앵커 **19,320개**에 대한 예측 |
| `t_c` — 정답 스칼라 | `y` — 박스 목록 (개수 가변) |
| `loss_fn` = 평균제곱오차 | `loss_fn` = **box + cls + dfl** (할당 절차 포함) |

가장 큰 구조적 차이는 **예측과 정답의 개수가 다르다**는 점이다.
예측은 앵커 19,320개로 고정이고 정답은 이미지마다 0~N개이므로, 손실을 계산하려면 **"어느 앵커가 어느 정답을 맡는가"를 먼저 정하는 할당(assignment) 단계**가 필요하다.

# 1. 모델 정의

## 1.1 구조

```
x (3 × 736 × 1280)
  → backbone (CSP 계열, 24 레이어)
  → neck (FPN + PAN)
  → head: 3개 스케일 P3 / P4 / P5  (stride 8 / 16 / 32)
```

| 스케일 | stride s | 격자 = ⌈H/s⌉ × ⌈W/s⌉ | 앵커 수 |
|---|---:|---|---:|
| P3 | 8 | 92 × 160 | 14,720 |
| P4 | 16 | 46 × 80 | 3,680 |
| P5 | 32 | 23 × 40 | 920 |
| | | **합계** | **19,320** |

각 앵커마다 채널 `no` 를 출력한다.

```
no = 4 × reg_max + nc = 4 × 16 + 1 = 65
```

- `nc = 1` — 사람 1클래스
- `reg_max = 16` — 박스를 좌표 4개가 아니라 **거리 분포 4개**로 표현 (DFL)

## 1.2 박스 표현 — 왜 좌표가 아니라 분포인가

앵커 점에서 박스의 네 변까지 거리 `d = (l, t, r, b)` 를 예측하는데, 각 거리를 실수 하나가 아니라 **0~15 범위의 확률분포**로 낸다.

$$
\hat{d} = \sum_{i=0}^{15} i \cdot \mathrm{softmax}(z)_i , \qquad z \in \mathbb{R}^{16}
$$

최종 박스는 앵커 좌표에서 이 거리만큼 떨어진 사각형이다.

$$
\text{box} = (\,x_a - \hat l s,\; y_a - \hat t s,\; x_a + \hat r s,\; y_a + \hat b s\,)
$$

분포로 두면 경계가 애매한 대상(풀에 가린 사람 등)에서 불확실성을 표현할 수 있다.

# 3. 손실함수 정의

## 3.1 전체 식

$$
\mathcal{L}(\theta) = \lambda_{box}\mathcal{L}_{box} + \lambda_{cls}\mathcal{L}_{cls} + \lambda_{dfl}\mathcal{L}_{dfl}
$$

$$
\lambda_{box}=7.5,\quad \lambda_{cls}=0.5,\quad \lambda_{dfl}=1.5
$$

## 3.2 할당 — TAL (Task-Aligned Assigner)

손실을 계산하기 전에 앵커 19,320개 중 **어느 것이 정답을 맡을지** 정한다. 정렬 점수가 높은 앵커를 정답마다 상위 `k`개 고른다.

$$
t = s^{\alpha} \cdot u^{\beta}, \qquad s = \text{분류 점수},\; u = \text{IoU}
$$

정답과 겹치면서(`u` 높음) 동시에 사람이라고 확신하는(`s` 높음) 앵커가 뽑힌다.
할당된 앵커만 box · dfl 손실에 들어가고, cls 손실은 **전체 앵커**에 대해 계산된다.

## 3.3 항별 정의

| 항 | 식 | 대상 |
|---|---|---|
| **box** | $\mathcal{L}_{box} = 1 - \mathrm{CIoU}(\hat{b}, b)$ | 할당된 앵커 |
| **cls** | $\mathcal{L}_{cls} = \mathrm{BCE}(s, t)$ — 목표값이 0/1이 아니라 **정렬 점수 `t`** | 전체 앵커 |
| **dfl** | 정답 거리 $d$ 양옆 두 정수 bin에 가중 교차엔트로피 | 할당된 앵커 |

$$
\mathcal{L}_{dfl} = -\big[(i{+}1-d)\log p_i + (d-i)\log p_{i+1}\big], \qquad i = \lfloor d \rfloor
$$

CIoU는 IoU에 **중심 거리**와 **종횡비** 항을 더한 것이다.

$$
\mathrm{CIoU} = \mathrm{IoU} - \frac{\rho^2(c,\hat c)}{diag^2} - \alpha v
$$

## 3.4 코드

```python
from ultralytics.utils.loss import v8DetectionLoss

batch = {
    "img":       im,                                  # (1,3,736,1280)
    "batch_idx": torch.zeros(len(lab)),               # 어느 이미지의 박스인지
    "cls":       torch.from_numpy(lab[:, :1]).float(),# (N,1)  클래스 = 0
    "bboxes":    torch.from_numpy(lab[:, 1:]).float(),# (N,4)  정규화 xywh
}
total, items = net.loss(batch)      # items = [box, cls, dfl] (가중치 적용 후)
```

# 4. 손실값 계산 — 실제 실행 결과

**입력**: 가림 지형 시험셋 `s20_34` 크롭 1장 (사람 긴 변 목표 34 px · 정답 1개)

| 항 | 가중 전 | 가중치 | 가중 후 |
|---|---:|---:|---:|
| box | 0.3421 | × 7.5 | **2.5656** |
| cls | 2.3968 | × 0.5 | **1.1984** |
| dfl | 0.7265 | × 1.5 | **1.0898** |
| | | **합계** | **4.8538** |

```
loss = 2.5656 + 1.1984 + 1.0898 = 4.8538   (배치 1장 기준)
```

**읽는 법**

- `box 0.342` = 평균 `1 − CIoU` → 할당된 앵커의 CIoU가 약 **0.66**. 위치는 대체로 맞다
- `cls 2.397` 이 상대적으로 크다 → **"여기에 사람이 있다"는 판단 자체가 어렵다**는 뜻
- 앞선 실험에서 "정답 중 26~32 %를 아예 못 찾는다(위치 오차는 작다)"고 측정된 것과 방향이 같다

# 5. 최적화

## 5.1 갱신 식

$$
\theta_{t+1} = \theta_t - \eta \big( \nabla_\theta \mathcal{L} + \lambda \theta_t \big) + \mu v_t
$$

## 5.2 설정값

| 항목 | 값 |
|---|---|
| 옵티마이저 | SGD · momentum 0.937 · weight_decay 0.0005 |
| 학습률 | lr0 0.01 → lrf 0.01 (선형 감쇠) · warmup 3 epoch |
| 배치 | 11s 16 · 11m 8 · 11l 6 (RTX 3090 24 GB) |
| 에폭 | 30 |
| 정밀도 | AMP (혼합 정밀도) |

## 5.3 체크포인트 선택

학습 중 저장되는 `best.pt` 는 손실이 아니라 **fitness** 로 고른다.

```python
fitness = mAP50-95          # ultralytics 8.4.102, 가중치 [0,0,0,1]
```

**즉 최소화하는 것(손실)과 모델을 고르는 기준(fitness), 합격 기준(AP50)이 서로 다른 대상 위에 정의되어 있다.**

import torch, numpy as np, cv2, glob

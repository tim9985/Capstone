## 지킬 것

- 편집 순서: 편집 **직전** `git pull` → 노트 몇 개 단위로 작게 `commit` → 바로 `push`
- push 가 거부되면 `git pull --rebase` 뒤 다시 push. 같은 줄이 충돌하면 덮지 말고 상대 세션에 알린다
- 노트북 · 서버 **모두** 볼트를 편집한다 (09-14 사용자 결정). 같은 노트를 동시에 고치지 않도록 기본 담당을 나눈다

  | 담당 | 노트 |
  |---|---|
  | 서버 | `08 서버` · 서버 실험 노트 (서버 E1~E8 · M1 등) · GPU 장애 이슈 · 서버에서 겪은 `07 개념` |
  | 노트북 | 나머지 — `00 홈` · `01` · `02` · `03` · `05` · `10` · `11` 등 |
  | 둘 다 | `09 기록/타임라인` · `다음 할 일` — **한 줄씩 추가만**, 남의 줄은 고치지 않는다 |

  담당이 겹치는 편집은 먼저 메시지로 알린다
- **공개 저장소**다
  - 원본 데이터 · 크롭 · 추론 결과 이미지 올리지 않기 (NOMAD · WiSARD · Okutama · AI-Hub 약관)
  - 요구명세서 · 주제제안서 hwpx 는 학번 · 연락처가 있어 **git 밖**
  - 내부 배포 주소 · 개인 이메일 넣지 않기
- 확정 문서는 **주제제안서 · 요구명세서 최신판** — 다른 문서와 어긋나면 이 둘이 우선

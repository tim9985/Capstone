## 모델 고르기

**Q1. 왜 YOLO11m 인가?**
- 실시간 (≤ 30 ms) 과 정확도의 균형 · 1080p 타일 4장에 18.9 ms · 11l 은 오히려 손해였고 (−3~−8 %), YOLO26m 은 맞바꿈 → [[5 YOLO 버전 비교와 우리 시험]]

**Q2. 공개된 항공 검출기를 쓰면 안 되나?**
- VisDrone 상위 모델 3개 모두 우리보다 낮고, 수직 시점 사람은 거의 0 · FlyPose 는 숲 · 비스듬은 높지만 한국 수직이 낮고 비상업 연구용 → 우리 조건으로 학습한 모델이 맞다

**Q3. 왜 1280 인가? 1920 통째로는?**
- 통째로 넣으면 사람이 2/3 로 줄어 작은 사람을 놓친다 · 1280×720 타일 4장 = 원래 해상도 · 학습 크기와 같음 → [[4 YOLO11 추론 - 타일 · NMS · 임계값 · TensorRT]]

## 성능 · 평가

**Q4. AP50 0.80 을 못 넘지 않았나?**
- 한국 수직 1.00 ✅ · 숲 0.66 · 비스듬 0.64 · 이 평가셋은 **운용보다 훨씬 작은 사람**이 많다 (숲 24 px 미만 21 % · 운용 16~20 m 는 60~100 px) · 운용 크기 (50~80 px) 재현율은 0.81~0.84

**Q5. 평가셋은 믿을 만한가?**
- 학습과 **장소가 겹치지 않는** 3개 (숲 WiSARD · 비스듬 Okutama · 한국 AI-Hub) · 숲 평가셋은 라벨 구멍 (라벨 안 된 띠 · 사람 14명) 을 확인해 무시 영역으로 처리

**Q6. 개선이 우연이 아니라는 근거는?**
- 같은 설정도 다시 학습하면 흔들린다 (비스듬 0.604~0.631) → **여러 번 학습한 평균끼리** 비교 · 평가셋을 블록으로 다시 뽑는 부트스트랩 95 % 구간이 0 을 넘어야 개선 → v12: 숲 +4.7 (+1.4 ~ +8.0) · 한국 +1.3 (+0.6 ~ +1.8)

**Q7. v12 는 무엇을 바꿨나?**
- 모델 · 설정은 그대로 · **데이터만** — 흐리게 키운 사람 없애기 · 같은 장면 반복 줄이기 · 라벨 없는 사람이 섞인 음성 빼기 · 자연 지형 · 한국 데이터 늘리기 → [[17 v12 데이터 재구성 - 파이프라인 점검 (10-12)]]

## 운용

**Q8. 오탐은 얼마나?**
- 사람 없는 장면 0.29~0.42 건/장 · 도로 장면 1.2 → 임계값 0.20 이면 0.55 (기준 ≤ 1) · 남은 오탐은 대부분 **사람 크기 물체** (수레 · 상자 · 표지물)

**Q9. 임계값은 어떻게 정했나?**
- 0.01~0.9 를 다 재 봤다 · F2 는 0.1~0.25 에서 거의 같아 **오탐 기준이 값을 정함** → 0.20 제안 · 두 단계 (낮게 추적 · 여러 장 확인) 도 UE 로 확인 예정

**Q10. 누운 사람 · 가려진 사람은?**
- 누운 사람도 「사람」 1클래스로 학습 (NOMAD · SARD · Archangel 자세 포함) · 자세는 탐지 위의 상태 층 (박스 모양 · 움직임 · 관절점) 에서 따로

**Q11. 실시간이 되나?**
- 탐지 18.9 ms (TensorRT FP16 · 3090) · 전체 연결 (추적 · 좌표 · 상태) 은 UE 녹화로 측정 예정 (NFR-V02 ≥ 5 FPS)

## 학습 방법

**Q12. 손실 함수는? 바꿔 봤나?**
- BCE (분류) + CIoU + DFL (박스) · 작은 물체용 NWD 는 −2.4 %p 로 기각 · 남은 오탐은 손실로 고칠 종류가 아님 → [[3 YOLO11 학습 - 손실 · TAL · DFL · EMA]]

**Q13. 학습을 더 오래 하면?**
- 60 에폭은 비스듬 −4.0 %p · v12 에서 30 에폭 더 학습을 다시 시험 중 (10-14)

**Q14. 데이터는 몇 장 · 어디서?**
- v12 = 18,601장 · 출처 11개 (VisDrone · NOMAD · WiSARD · AI-Hub · HERIDAL · SARD · Archangel · LADD · NII-CU · Unicamp) · 비스듬 50 % · 한국 수직 14 %

**Q15. 실기체 · 실제 장소에서도 되나?**
- 중간발표는 **UE 시뮬레이션에서 전 과정** · 실기체 · 자체 촬영 평가는 그 뒤 · 공개 데이터는 학습 장소와 다른 장소에서만 평가했다

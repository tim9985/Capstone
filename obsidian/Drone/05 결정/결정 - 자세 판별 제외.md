> [!check] 결정
> **자동 자세 판별(쓰러짐 분류)은 구현하지 않는다.**
> 사람은 **1클래스**로 탐지하되 누운 사람·부분 가림을 포함해 찾고, **쓰러짐 여부는 운영자가 스냅샷을 보고 판단**한다.

## 요구명세서 근거 (v1.7 최종판)

| 위치 | 내용 |
|---|---|
| 1.2 목표 | 쓰러진 사람과 부분적으로 가려진 사람을 **포함하여 탐지** — 사람 탐지 AP50 0.80 이상 |
| UC-0701 사람 후보 탐지 | 쓰러짐·부분 가림을 포함한 사람 후보를 검출 |
| **UC-0705 후보 판단 기록** | "시스템은 **자세를 자동 분류하지 않으며**, 쓰러짐 여부는 운영자 판단으로 기록한다." |
| AT-P02 | 누운 사람·부분 가림 사례의 **재현율을 따로 기록** |
| 성능 요구 | 쓰러짐 재현율 목표(옛 NFR-V07)는 v1.3 에서 삭제 |

## 왜

| 이유 | 근거 |
|---|---|
| **다른 장소에서 무너진다** | 3클래스 모델 SARD test 쓰러짐 재현율 0.974 → 미학습 Okutama **0.091** → [[쓰러짐 판별 도메인 이전 실패]] |
| **하향 시점엔 단서가 적다** | 하향 90° 에서 서 있는 사람은 머리·어깨 덩어리 18~39 px → [[1 기준 조건 - 카메라·화각·마운트]] |
| **라벨 품질의 천장** | NOMAD·Okutama 자세는 활동 구간에서 유도한 라벨. 사람이 붙인 SARD 만 잘 됨 |
| **분류 오류가 위험하다** | 쓰러진 사람을 "서 있음"으로 잘못 분류해 알림 순위가 내려가면 구조가 늦어진다. 운영자는 스냅샷으로 더 정확히 본다 |
| **누운 사람은 오히려 잘 보인다** | 몸 전체가 보여 71~133 px — 1클래스 탐지로 충분히 찾을 수 있다 |

## 대안

| 대안 | 왜 아닌가 |
|---|---|
| 3클래스 자세 탐지 계속 | 9번 시도, 도메인 이전 실패 → [[자세 1~6차 실패 기록]] · [[자세 8차 - 3클래스 동결]] |
| 탐지 후 크롭을 따로 분류 (2단계) | 같은 라벨·시점 문제를 그대로 안는다. 한국 하향 촬영 데이터 없이 검증 불가 |
| **1클래스 탐지 + 운영자 판단** ✅ | 요구명세서와 일치 · 비전 노력을 미탐·오탐·색상 비교에 집중 |

> [!abstract] 한 줄
> **AP** = 한 클래스에 대해, 점수 기준을 바꿔 가며 그린 **정밀도-재현율 곡선의 넓이** (0~1).
> **mAP** = 여러 클래스의 AP 를 **클래스 수로 나눈 평균**.
> 뒤에 붙는 **50 · 50-95** = 정답으로 인정하는 **[[IoU]] 기준**.

## 1. AP — 한 클래스의 정확도
1. 모델이 낸 박스를 점수 높은 순으로 줄 세운다
2. 점수 기준을 1 → 0 으로 내리며, 기준마다 [[정밀도와 재현율]]을 계산한다
3. 가로축 재현율 · 세로축 정밀도로 곡선을 그린다
4. **곡선 아래 넓이 = AP**

```
정밀도
 1 ┤■■■■■■■
   │       ■■■■
   │           ■■■
   │              ■■
 0 ┼────────────────── 재현율
   0                 1
   넓이가 클수록 = 놓치지 않으면서 헛것도 안 잡는 모델
```
**특징**: 특정 점수 기준 하나가 아니라 **모든 기준을 뭉친 요약**이다.

## 2. mAP — 여러 클래스의 평균
```
mAP = (사람 AP + 차 AP + 자전거 AP + …) ÷ 클래스 수
```

> [!important] 우리는 클래스가 하나다
> 탐지 대상은 **사람 1클래스** (쓰러짐 판단은 운영자, UC-0705 후보 판단 기록).
> 평균할 대상이 없으므로 **mAP50 = 사람 AP50** — 값은 같고 이름만 부정확하다.
> 요구명세서는 **"사람 AP50"** 으로 쓰는 게 정확하다.

## 3. 50 · 75 · 50-95 — IoU 기준

| 지표 | 정답 인정 기준 | 보는 것 |
|---|---|---|
| **AP50** | IoU **0.50 이상** | 사람을 **찾았나** (위치가 대충 맞으면 인정) |
| AP75 | IoU **0.75 이상** | 박스를 **꽤 정확히** 쳤나 |
| **AP50-95** | IoU 0.50, 0.55 … 0.95 **10단계** AP 의 평균 | 찾은 것 + 박스를 **딱 맞게** 쳤나 |

- AP50-95 는 항상 AP50 보다 낮다 — [[stage1_all]]: **AP50 0.850 · AP50-95 0.605**
- COCO 대회 공식 지표는 AP50-95

## 4. 우리 명세서에는 무엇이 맞나
| 지표 | 쓰임 |
|---|---|
| **AP50** | ✅ **합격 기준**. 목적은 사람을 찾는 것, 박스 몇 px 정확도는 위치 신고에 영향 없음 |
| AP50-95 | 참고 기록. 작은 대상은 몇 px 차이로 크게 흔들려 합격선으론 부적합 |
| 기준 0.15 에서의 재현율 | ✅ **함께 기록**. AP 는 모든 기준을 뭉친 값이라 운용에서 몇 명 찾는지는 따로 봐야 함 |

> [!note] 나중에 여러 클래스가 되면
> 사람·쓰러짐 등으로 나누면 평균(mAP)이 아니라 **클래스별 AP 를 따로** 기준으로 건다.
> 3클래스 자세 모델: 사람 0.668 · 쓰러짐 0.702 · 애매 0.473 → mAP 0.614 — 중요하지 않은 클래스가 평균을 끌어내리고 쓰러짐 성능이 가려진다.

> [!tip] AP50-95 가 쓰이는 곳
> 학습 프로그램(Ultralytics)이 "가장 좋은 모델"을 고르는 점수 = `0.1 × AP50 + 0.9 × AP50-95` → [[fitness와 조기 종료]]

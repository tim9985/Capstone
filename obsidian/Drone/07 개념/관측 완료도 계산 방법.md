> [!abstract] 한 줄
> 정찰 구역을 **작은 칸(격자)으로 나누고**, 영상 한 장마다 **땅의 어느 칸을 덮는지** 계산해 칸마다 상태를 매긴다. 칸 수를 세면 면적이 된다.

## 기본 원리

```
① 임무구역을 5 m × 5 m 칸으로 나눈다 (처음엔 전부 "미관측")

② 사진 한 장마다 촬영 영역을 계산한다
   드론 위치·고도·자세 + 카메라 화각(54° × 32°)
   → 사진 네 모서리를 땅에 투영 → 사다리꼴 "찍힌 영역"
   (좌표 변환 코드로 네 모서리를 계산)

③ 찍힌 영역 안의 칸마다 상태 판정
   → 유효 관측 / 품질 부족 / 가림

④ 칸 수 × 25 m² = 상태별 면적 → 지도에 색 + 숫자로 표시
```
고도 30 m 에서 사진 한 장 ≈ 땅 30 × 17 m. 드론이 날며 사다리꼴이 **도장처럼** 지도에 찍힌다. → [[GSD와 화각]]

## 상태별 판정

> [!tip] 단계별 절차·의사코드·기존 기법 비교 → [[관측 상태 판정 알고리즘]]

| 상태           | 필요한 데이터                       | 판정 방법                                                        | 난이도     |
| ------------ | ----------------------------- | ------------------------------------------------------------ | ------- |
| **유효 관측**    | 위치·자세, 촬영 시각                  | 찍힌 영역 안 + 품질 검사 통과 → 관측 횟수·마지막 시각 누적                         | 쉬움      |
| **관측 품질 부족** | 기울기·자세 변화·고도·흐림               | 기울기 6° 초과, 시각 동기 실패, 흐린 사진, 사람이 너무 작게 찍히는 고도 → "찍혔지만 인정 안 함" | 쉬움      |
| **운용 제한**    | 비행금지 구역, 제외 구역, 비행 고도보다 높은 건물 | **임무 시작 전** 표시 + 비행 중 경로 불가 구역 추가                            | 쉬움      |
| **가림 (건물)**  | 건물 윤곽 + **높이**                | 카메라에서 칸까지 직선 → 중간에 건물 있으면 가림. 높이 없으면 "미확인"                   | 보통      |
| **가림 (나무)**  | 산림 지도 또는 영상의 초록 비율            | 수관 아래는 확인 불가 → **보수적으로 "가시성 미확인"**                           | **어려움** |
| **미관측**      | —                             | 위에 해당 없고 아직 안 찍힌 칸                                           | 자동      |

> [!important] 상태가 겹칠 때
> 한 번이라도 유효하게 보면 **유효 관측 유지**. 한 위치에선 가렸어도 다른 위치에서 보이면 관측으로 바뀐다.
> "드론이 지나간 것만으로 관측 완료 처리하지 않는다" (요구명세서 3.3절)

## 완료도 계산
```
관측 가능 완료도 = 유효 관측 칸 ÷ (전체 칸 − 제한 칸) × 100   ← NFR-I01 기준 90%
전체 구역 완료도 = 유효 관측 칸 ÷ 전체 칸 × 100
```
화면 예: 미관측 회색 · 유효 초록 · 품질 부족 노랑 · 가림 보라 · 제한 빨강 + "미관측 1,240 m² · 가림 380 m²"

## 우리 장비로 가능한가
| 항목    | 판단                                                          |                       |
| ----- | ----------------------------------------------------------- | --------------------- |
| 계산량   | 500 × 500 m 를 5 m 칸 → 1만 칸, 사진 한 장 판정 수 ms. 초당 1~2회 갱신이면 충분 |                       |
| 위치 오차 | GPS 수 m → **5 m 칸이 적당** (2 m 이하는 무의미)                       |                       |
| 산지    | 평지 가정 시 경사지에서 영역이 틀어짐 → **수치표고모델(DEM)** 반영                  |                       |
| 건물 가림 | 건물 높이 필요 — [[상황지도와 기본 지도                                    | 2.5차원 상황지도]]가 원래 이 목적 |
| 나무 가림 | 정확한 판정 불가 → "못 봤는데 봤다고 하지 않기"가 목표                           |                       |

## 단계별 구현
1. 격자 + 찍힌 영역 + 품질 검사 + 제한 구역 → 미관측·유효·품질 부족·제한 + 완료도
2. DEM 반영 (산지 보정)
3. 건물 높이로 가림 계산, 숲은 가시성 미확인

**검증** — 시뮬레이터는 깊이 영상으로 정답 가시 영역을 얻어 비교 / 실제 비행은 가려진 곳·드러난 곳에 표식

> [!abstract] 한 줄
> **PCIe** 는 GPU 와 CPU 를 잇는 고속 통로다. 세대가 오를수록 빠르지만 신호가 예민해진다. **ASPM**(절전)과 **AER**(오류 보고)은 이 통로의 부가 기능이다.

## 세대

| 세대 | 한 가닥 속도 | x16 대략 |
|---|---|---|
| Gen3 | 8 GT/s | 약 16 GB/s |
| Gen4 | 16 GT/s | 약 32 GB/s |

- 3090 과 우리 서버 슬롯(CPU 직결 x16)은 Gen4 까지 된다
- 쉬는 동안 2.5 GT/s 로 내려가는 건 절전이라 정상이다. 부하가 걸려야 제 속도로 올라간다

## 왜 Gen3 로 낮췄나

- Gen4 는 신호가 두 배 빨라 슬롯 접촉 · 기판 · 라이저 케이블 품질에 더 예민하다. 신호가 흔들리면 GPU 가 통로에서 떨어질 수 있다 → Xid 79 후보 → [[GPU 장애 Xid 79]]
- 학습은 데이터를 GPU 에 올려 두고 계산하는 시간이 대부분이라, 통로 속도를 절반으로 줄여도 **손해가 작다**
- 방법: GPU 가 꽂힌 상위 포트의 목표 속도를 Gen3 로 바꾸고 링크를 다시 맺는다 (`setpci`)
  - **학습 중에는 다시 맺지 않는다** — 그 순간 GPU 가 떨어질 수 있다
- 확인: 부하 중 `nvidia-smi --query-gpu=pcie.link.gen.current --format=csv` 가 3

## ASPM · AER

| 기능 | 뜻 | 우리 서버 |
|---|---|---|
| **ASPM** | Active State Power Management — 쉴 때 통로 전력을 줄이는 절전 | `pcie_aspm=off` 로 꺼 둠 |
| **AER** | Advanced Error Reporting — 통로 오류를 로그에 남기는 기능 | `pci=noaer` 로 꺼 둠 → **오류 증거가 안 남는다** |

관리자 점검 요청에 "진단할 때 `pci=noaer` 를 빼고 부팅"이 들어간 이유다.

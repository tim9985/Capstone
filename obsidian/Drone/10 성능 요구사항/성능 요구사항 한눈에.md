> [!summary] 성능 요구사항이란
> 시스템이 **"영상을 받아 → 사람을 찾고 → 위치를 계산해 → 지도에 올리는"** 흐름의 각 구간을
> **얼마나 빠르게 · 정확하게 · 빠짐없이 · 안정적으로** 해내야 하는지 **숫자로 정한 합격선**이다.
> 요구명세서 3.1절 · 드론·게이트웨이·중앙 서버 각 1대 기준.

## 흐름 속에서 각 항목이 재는 곳

```
[시작 전]  P01 연결 판정 ─ 장치들이 다 연결됐는지 빨리 알 수 있나

드론 촬영 ──▶ 영상 수신 ──▶ 사람 탐지 ─────────────────▶ 좌표 계산 ──▶ 상황지도
            P02 잘 받나    V01 한 장 몇 ms              V04 위치 정확도   I01 빠짐없이 봤나
                           V02 초당 몇 장
                           V03 얼마나 정확히 찾나
                           V05 몇 점부터 사람으로 인정
                           V06 헛탐지가 얼마나 적나

[운용 중]  P03 장애 감지 ─ 끊기면 몇 초 안에 알아채나
[전체]     P04 동시 처리 ─ 위 작업을 한꺼번에 해도 버티나
```

## 헷갈리기 쉬운 짝

> [!tip] V01 vs V02
> **V01** = 모델이 한 장을 푸는 속도 (엔진 성능)
> **V02** = 시스템 전체가 1초에 내놓는 결과 수 (실제 주행 속도)

> [!tip] P02 vs V02
> **P02** = 영상을 **잘 받았나** · **V02** = 받은 영상을 **분석했나**
> 받는 게 초당 5장이 안 되면 분석도 5장이 될 수 없다.

> [!tip] V03 vs V06
> **V03** = 사람이 **있을 때** 잘 찾나 · **V06** = 사람이 **없을 때** 헛것을 안 잡나
> 둘은 서로 당긴다 — 기준을 낮추면 V03 은 좋아지고 V06 은 나빠진다 → [[NFR-V05 신뢰도 기준]]

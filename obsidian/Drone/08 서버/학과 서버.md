## 사양

| 항목 | 값 |
|---|---|
| OS | Ubuntu 22.04 |
| CPU · RAM | i9-11900 · 64 GB |
| GPU | **RTX 3090 24 GB** |
| 저장 공간 | 약 5 TB |
| 접속 | MobaXterm → JupyterLab |
| 작업 경로 | `~/JupyterLAB/drone_dev` |
| Claude 세션 | "Drone-우분투" |

## 서버에서 할 수 있는 것 / 없는 것

| 된다 | 안 된다 |
|---|---|
| 모델 학습 · 스윕 | Unreal 시뮬레이터 화면 확인 |
| 대량 평가 · 영상 일괄 추론 (`video_infer.py`) | 실시간 창 (`live_view.py`) |
| 데이터 전처리 · 모음판 이미지 생성 | |

## 설정 원칙

- `ultralytics==8.4.102` — 노트북 기준선과 비교하려면 버전 고정
- torch 는 드라이버 CUDA 버전에 맞춘다
- 긴 작업은 **tmux** 에서 — JupyterLab 셀은 연결이 끊기면 죽는다
- 재부팅하면 tmux 가 전부 죽는다 → rclone 은 같은 명령 재실행, gdown zip 은 `unzip -t` 확인

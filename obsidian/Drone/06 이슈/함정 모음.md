## 학습·평가

| 함정 | 증상 | 해결 |
|---|---|---|
| **조기 종료 기준** | mAP50 이 올라도 멈춘다 | Ultralytics 는 `fitness = 0.1·mAP50 + 0.9·mAP50-95` → [[fitness와 조기 종료]] |
| **초반 에폭 하락** | ep2 0.551 → ep3 0.310 | warmup 때문. 끊지 말 것 |
| **소표본 결론** | 70장으로 "WiSARD 0.883 유지" → 전체 0.804 | 전체로 잰다 |
| **WiSARD val 앞 291장** | `--limit` 평가가 비어 나옴 | 라벨 있는 이미지에서 고르게 추출 |
| **합성 데이터 0장** | 에러 없이 실사만 학습 | `*.jpg` 만 찾고 합성은 `.png` 였다 → 0장이면 중단하도록 |
| **results.csv 를 엑셀로 열기** | 파일 잠금으로 학습 사망 | 열지 말 것 |
| **`--resume` 노트북 가중치** | 이어학습 깨짐 | Windows 경로가 박혀 있다 → `--weights` |

## 데이터

| 함정 | 증상 | 해결 |

## 환경·도구

| 함정 | 증상 | 해결 |
|---|---|---|
| **`wmic`** (Windows 11 제거) | 학습 중인데 "끝남" 판정 → 평가 동시 실행 · RAM 0.5 GB | 최종 가중치 **파일 생성**을 기다린다 |
| **Git Bash 에서 `C:\…python.exe`** | command not found | PowerShell 또는 `/c/…` |
| **cp949** | yaml·한글 읽기 실패 | `encoding="utf-8"` |
| **NumPy 2** | `ndarray.ptp` 없음 | `np.ptp` |
| **gdown 5.x** | `--remaining-ok` · `--fuzzy` 인식 못 함 | 옵션 제거 · 폴더는 rclone |
| **rclone config update** | OAuth 다시 뜸 | `export RCLONE_DRIVE_ROOT_FOLDER_ID=…` |
| **rclone 작은 파일 수천 개** | 매우 느림 | `--drive-pacer-min-sleep 10ms --drive-pacer-burst 200` |

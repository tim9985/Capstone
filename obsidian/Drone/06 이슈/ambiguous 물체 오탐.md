> [!warning] 실영상에서 ambiguous 가 벤치·가방 같은 **물체**에 붙는다
> Okutama 2.2.10 · [[pose3_sn_freeze]] 탐지의 **47.3%** 가 ambiguous

## 진단 과정

1. 처음 가설: "서 있는 사람을 ambiguous 로 잘못 분류" → **틀림**
2. 스냅샷을 영상 전체에 고르게 뽑아 보니 **물체**였다
3. 새 가설: SARD `not_defined` (가려짐·너무 작음) 가 원인 → [[자세 9차 - not_defined 제외]]
4. 빼 보니 오탐 **−58%** → **원인 확인**. 그러나 NOMAD 발견율 −0.086 이라 기각

## 절충안 (보류)

```
큰 not_defined (예: 30 px 이상) → 배경      ← 물체 오탐 유발
작은 not_defined               → ambiguous  ← 진짜 작은 사람
```

`not_defined` 박스 중앙값 43 px — 경계가 두 집단을 실제로 가르는지 분포부터 확인해야 한다.

## 운용에서의 의미

- 관제사가 벤치를 한 번 보고 넘기는 비용 < 요구조자를 놓치는 비용
- 그래도 오탐이 많으면 관제사가 알림을 무시하게 된다 → **오탐 표시 피드백** 필요 → [[관제 뷰어 프로토타입]]

### 라벨 형식

```json
{"annotations": [{"type": "bbox", "attributes": {"person_pose": "lying"},
                  "points": [[x1,y1],[x2,y1],[x2,y2],[x1,y2]], "label": "person"}],
 "filename": "...-90-20m-14h25m_0004224.jpg",
 "Metadata": {"altitude": 20, "angle": 90, "weather": "SUN", "time": "PM", "places": "mit", "date": "2021-01-04"}}
```

- 프레임마다 JSON 한 개 · 박스는 **4점 폴리곤** → 변환할 때 min/max 로 박스를 만든다
- 파일명에도 `각도-고도` 가 들어 있다 (`...-90-20m-...`)

## 받는 법

```bash
mkdir -p ~/.config/aihub && (umask 077; read -rsp 'AI-Hub API key: ' K; echo; printf '%s' "$K" > ~/.config/aihub/api_key)
curl -o ~/bin/aihubshell https://api.aihub.or.kr/api/aihubshell.do && chmod +x ~/bin/aihubshell
~/bin/aihubshell -mode l 182 > filetree.txt          # 파일 목록 · filekey (키 없이 됨)
cd ~/JupyterLAB/Capstone/drone_yolo && ./aihub182_dl.sh   # 고른 원천을 순차 다운로드
```

- 속도 **약 140 MB/분** (2.4 MB/s) — 30 GB zip 이 3.5시간. 전부 받으면 약 4.5일이라 **골라서** 받는다
- 09-16 선택: 시흥_의왕_화성01(30 GB · 학습) · **화성26**(11 GB · Validation → 장소 분리 시험셋) · 안산01(15 GB) · 의왕03(17 GB)

> [!warning] 다운로드 함정
> - 여러 filekey 를 한 번에 받으면 `download.tar` 하나로 오고 스크립트가 **병합(merge)** 한다. 중간에 끊기면 `*.zip.part0` 만 남는다 — 09-16 라벨 45개 중 **13개가 이 상태**여서 다시 받았다
> - zip 안 파일명이 CP949 라 `unzip` 이 경고를 내지만 central 이름(UTF-8)으로 풀린다
> - 원본 · 파생물은 **git 에 올리지 않는다** (약관)

## 3. 프레임 추출과 라벨

1. **순차 디코딩**으로 프레임 추출 — H.264 에서 임의 위치로 건너뛰면 프레임이 어긋난다 → [[함정 모음]]
2. 비슷한 연속 프레임 제거 (SSIM 0.95 이상이면 버림)
3. **사전 라벨** — 그때까지의 최고 모델로 `conf 0.05 · imgsz 1920` 추론 → 박스 초안
4. **사람이 수정** — CVAT 또는 Label Studio (로컬 설치, 외부 업로드 없음)
5. 라벨 규칙

| 상황 | 규칙 |
|---|---|
| 박스 | 보이는 몸 전체 (그림자 제외) |
| 부분 가림 | 보이는 부분만 |
| 8 px 미만 | 라벨하지 않음 (평가에서도 제외) |
| 사람인지 애매 | 박스 + `difficult` 표시 → 평가에서 제외 |
| 자세 속성 | `lying / standing / sitting` 별도 기록 (클래스는 사람 하나) |

6. `label_review.py` 모음판으로 전수 훑기 → 10% 는 다른 사람이 교차 확인
7. **git 에 올리지 않는다** (얼굴·위치가 담긴 영상). Capstone 저장소는 공개다

## 5. 시연 장비에 올리기 (S8)

### 내보내기

```bash
# TensorRT 엔진은 GPU 마다 따로 만든다 → 시연 장비(RTX 4080 SUPER)에서 실행
yolo export model=best.pt format=engine half=True imgsz=736,1280 device=0
# 호환용
yolo export model=best.pt format=onnx imgsz=736,1280 opset=17
```
- `736,1280` — 1920×1080 을 1280×720 으로 줄이고, 32 의 배수로 맞춘 세로 736
- 내보낸 엔진으로 `test_v2` 를 **다시 재서** 원본 `.pt` 와 AP50 차이 0.005 이내인지 확인 (FP16 손실 점검)

### 속도 (AT-P01)

| 측정 | 방법 |
|---|---|
| 한 장 시간 | 1920×1080 프레임 1,000장 · 전처리(축소·정규화)+추론+후처리 · 평균·P95 |
| 합격 | 평균 **≤ 30 ms** (NFR-V01) |
| 참고 | 4080 SUPER · yolo11s · 1280 에서 56.5 fps 실측 (08-31, `.pt`) |

### 운용 설정

| 설정 | 값 | 근거 |
|---|---|---|
| conf | **자체 A·B 검증셋**에서 오탐 ≤ 1 을 지키며 F2 최대 (C 에서 고르면 안 됨) | [[NFR-V05 신뢰도 기준]] |
| iou (NMS) | 0.5 | 위에서 보면 사람끼리 거의 안 겹친다 |
| max_det | 100 | |
| 추적 | ByteTrack (`tracker_ab.py` 비교 결과) | 단발 오탐 거르기 → [[NFR-V06 프레임 오탐]] |

### 작은 사람을 놓칠 때의 대안

`own_siteC` 에서 16~24 px 구간 발견율이 낮으면, 속도 예산 안에서 고른다.

| 대안 | 효과 | 비용 |
|---|---|---|
| 추론 입력 1600 | 사람 1.25배 | 시간 약 1.6배 |
| 추론 입력 1920 | 사람 1.5배 | 시간 약 2.2배 (노트북 3050 에서 38 ms) |
| 타일 2장 (좌·우 절반씩 1280) | 사람 1.5배 | 시간 약 2배 |
| 운용 고도 상한을 낮춤 | 확실 | 탐색 속도 손실 → [[NFR-I01 관측 완료도]] |

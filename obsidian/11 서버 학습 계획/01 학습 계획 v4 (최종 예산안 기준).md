# 학습 계획 v4 — 최종 예산안 기준

## 1. 전제 (확정)

- 카메라: RunCam WiFiLink 2-G · IMX415 · 1920×1080 · H.264
- 화각 **88°** (f 994 px · 수직 57.0°)
- **3축 짐벌** (GM3 V2) → 마운트각을 비행 중 지정 · 흔들림 보정
- 게이트웨이 RPi 4B 2GB → **추론은 서버**
- 고도 16~30 m (요구명세)

## 2. 운용 방식 — 🟡 제안

- **주 탐색: 짐벌 하향 90° 고정**
  - 학습 데이터·평가셋(test_v2)·AI-Hub 가 전부 수직 → 시점 일치
  - 좌표 오차 최소 (3.1 m)
  - 증강 `degrees 180 · flipud 0.5` 그대로 유효
- **재관측(UC-0706): 짐벌 틸트 + 저고도**
  - 대상이 커져 판정 쉬움 · 별도 학습 불필요
- 비스듬 주 탐색(30~60°)은 채택 안 함
  - Okutama 실측: 비스듬이 수직보다 −4.2 %p
  - 30° 는 화면 상단이 지평선 근처 → 원리상 탐지 불가 구역 발생

## 3. 커버 범위

- 실제 사람 크기 (88° · 하향 90° · 16~30 m · 화면 전체 · 서 있음/누움): **27~106 px**
- 학습 노출 범위 = 전처리 목표 × scale(0.7~1.3)
- **전처리 목표: 로그균등 38~81 px** → 학습 노출 27~105 px
- 현재 16~160 px 폐기 (하한·상한 모두 운용 범위 밖 낭비)

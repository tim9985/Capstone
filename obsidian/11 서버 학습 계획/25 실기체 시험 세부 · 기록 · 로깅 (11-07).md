# 실기체 시험 세부 · 기록 · 로깅 (11-07)

> 기체 도착 · **11-09 (월) 조립 → 시험** · 합격선 · 순서 = [[24 실기체 비전 시험 시나리오 (11-04)]] · 장면 코드 = [[14 촬영 체크리스트 - 자세 × 가림 (10초)]]
> 원칙: **나중에 다시 돌릴 수 있게 남긴다** — 영상 원본 · 시각 · 기체 자세 · 정답 (출연자 위치 · 자세 · 옷) 이 없으면 그날 비행은 수치가 안 나온다

## 0. 하루 흐름

| 시각 | 할 일 | 남길 것 |
|---|---|---|
| 비행 전 30분 | 서버 · worker 확인 (1.3 · 녹화 켜짐 · `time_source`) · 시계 맞추기 (폰 · 노트북 · 서버 · 기체) | 상태 파일 캡처 · 시계 차이 (초) |
| 비행 전 15분 | 카메라 설정 고정 · 체커보드 10장 (첫날만) · 지상 기준점 · 출연자 위치 표시 | 설정값 · 기준점 좌표 |
| 비행마다 | 이륙 → **장면 코드 말하기** → 10~15초 → 다음 · 배터리 경고 25 % 에서 복귀 | 기록지 한 줄 / 장면 |
| 비행 직후 | 녹화 폴더 크기 · 장 수 확인 · 기체 로그 내려받기 | 파일 목록 · sha256 |
| 그날 밤 | `real_flight_eval.py` 자동 채점 · 라벨 내보내기 | `metrics/real_flight_<임무>.json` |

## 1. 자동으로 남는 것 — 켜졌는지만 확인

| 무엇 | 어디 | 확인 |
|---|---|---|
| 분석한 프레임 원본 (JPEG) | `VISION_RECORD_DIR/<임무>/frames/*.jpg` | 비행 1분 뒤 장 수 늘어나는지 |
| 프레임마다 시각 · 기체 자세 · 분석 요약 | `poses.jsonl` (`capture_at` · `pose` · `sha256` · 관측 박스 · 색 · 등급) | `pose` 가 비어 있지 않은지 (비면 위치 못 냄) |
| worker 상태 | `worker-status.json` (`fps` · `latency_ms_p50` · `frames_dropped` · `time_source` · `geo_ok_ratio` · `record_frames` · `record_full`) | 비행 중 1분마다 화면 캡처 또는 복사 |
| 후보 · 관측 (관제로 간 것) | 백엔드 outbox · 후보 목록 | 관제 화면 캡처 (시연 자료) |
| 기체 비행 로그 | 비행 제어기 로그 (`.bin` · `.tlog`) · GPS · 고도 · 자세 · 짐벌각 | 비행마다 내려받기 · 파일 이름에 비행 번호 |
| 영상 원본 (가능하면) | RunCam 쪽 녹화 (SD 카드) | 전송 화질과 비교용 · 압축 손해 판정 |

> ⚠ `VISION_RECORD_MAX_MB` 기본 3,000 MB — 넘으면 녹화만 멈춘다 (`record_full`) · 하루 비행 전 비우거나 늘린다

## 2. 사람이 적어야 하는 것 — 기록지 (비행마다 · 장면마다 한 줄)

| 칸 | 예 | 왜 |
|---|---|---|
| 비행 번호 · 장소 (A · B · **C 평가 전용**) | F03 · C | 학습 / 평가 나누기 |
| 장면 코드 | `P8-O0-앞` | 장면별 재현율 (`segments`) |
| 시작 · 끝 시각 (초까지) | 14:05:10 ~ 14:05:25 | 녹화와 맞추기 |
| 고도 (m) · 짐벌각 (°) · 기체 동작 (호버 · 이동 · 선회) | 16 · 45 · 호버 | 고도별 · 움직임 영향 |
| 출연자별: 이름 · 자세 · 상의 색 (12색) · 위치 (기준점 번호 또는 GPS) | 홍길동 · 누움 · 빨강 · K3 | 정답 (탐지 · 등급 · 색 · 위치) |
| 가림물 · 바닥 (풀 · 흙 · 아스팔트) · 그늘 여부 | 덤불 O2 · 풀 · 그늘 | 실패 원인 나누기 |
| 날씨 · 해 방향 (역광 · 순광) · 바람 체감 | 맑음 · 역광 · 약 | 조건별 |
| 관제 화면에서 본 것 (뜸 · 안 뜸 · 등급) | 뜸 · 높음 (12초) | 실시간 판정 기록 |
| 특이 사항 | 링크 끊김 3초 | |

- 출연자 옷 사진 1장씩 (지상에서) — 색 정답 다툼 방지
- **빈 장면 (T2) 에 미끼 물체** — 흰 의자 (옷 걸쳐서) · 배낭 · 옷 더미 · 15 m · 30 m (UAV-SAR 헛탐지 대부분이 이것 · 11-08) → D1 하드 네거티브
- 장면 시작 때 **카메라를 향해 코드 말하기** + 손뼉 (영상 · 소리 시각 맞춤)

## 3. 카메라 · 전송 설정 — 첫날 고정하고 바꾸면 기록

| 항목 | 값 | 이유 |
|---|---|---|
| 해상도 · 프레임 | 1920×1080 · 30 fps | 모델 입력과 같게 |
| 노출 · 화이트밸런스 | 자동 끄기 (가능하면) · 바꾸면 기록 | 색 판정 흔들림 |
| 전송 비트레이트 · I 프레임 간격 | 8 Mbps 쪽 · 값 기록 | 압축이 누운 사람 −10 %p (실험) |
| 렌즈 | LN012 88° (바꾸면 기록) | 위치 계산 화각 |

## 4. 비행 후 판정 — 무엇을 어떻게 셈

| 지표 | 계산 | 기준 |
|---|---|---|
| 누운 사람 재현율 | 장면 코드 P8 · P9 · P10 프레임에서 출연자 박스 찾음 비율 (16 · 20 m 따로) | ≥ 0.80 |
| 헛탐지 | T2 빈 장면 프레임 · 문턱 0.20 박스 수 / 장 · **무엇을** 잘못 찾았나 그림 | ≤ 1 건/장 |
| 처리 | 상태 파일 `fps` · `latency_ms_p50` · 떨어진 장 | ≥ 5 장/초 |
| 위치 | 출연자 기준점 vs 후보 위경도 · 중앙 · P95 | ≤ 10~15 m |
| 등급 | 누움 · 정지 ≥ 10초 장면에서 「높음 · 긴급」 이 뜬 시각 (초) · 앉음 · 서기가 높음으로 오른 횟수 | 참고 |
| 색 | 출연자 상의 1순위 맞음 · 「빨간 옷」 질의 순위 | 참고 |
| 후보 쪼개짐 | 출연자 1명당 후보 수 | 참고 (지금 4~5) |
| 모델 비교 | 같은 녹화를 v12 · M · MN 으로 다시 → 누움 교체 기준 ([[_학습 큐]] 11-04) | 짝 구간 > 0 |

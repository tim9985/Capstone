## 왜

통합 mAP50 0.850 안에 **여름 0.641** 과 **겨울 0.922** 가 섞여 있었다.

## 우리 평가 도메인 (`eval_pose3.py`)

| 도메인 | 재는 것 | 학습에 썼나 |
|---|---|---|
| NOMAD 탐지 | 사람 발견율 (클래스 무시) | 검증 배우만 |
| WiSARD 탐지 | 사람 발견율 | 검증 비행만 |
| **Okutama (미학습)** | 사람 발견율 | **안 씀** |
| SARD test | 쓰러짐 재현율·정밀도 | 안 씀 |
| SARD val | 쓰러짐 재현율 | 검증 |
| NOMAD 자세 val | 쓰러짐 재현율 | 검증 |

설정: conf 0.15 · IoU 0.3 · 탐욕 매칭

## 원칙

- **분할 단위** — NOMAD 는 배우, WiSARD 는 비행, Okutama 는 영상. 프레임 단위로 섞으면 부풀려진다
- **같은 잣대** — 모델이 달라도 같은 코드·같은 표본·같은 임계값
- **판정 기준은 결과 보기 전에** 적는다
- **미학습 도메인**이 진짜 실력이다

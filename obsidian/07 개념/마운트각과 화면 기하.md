> [!abstract] 한 줄
> **마운트각** = 카메라 광축이 수평에서 아래로 기운 각 (90° = 수직 하향). 비스듬하면 **화면 위는 멀고 아래는 가깝다** — 같은 사람도 화면 위치마다 크기가 달라진다.

![[fig_60도_화면기하.svg]]

## 계산 (`coord_error.py` · `make_px_table.py` 와 같은 식)

```
f   = (W/2) / tan(HFOV/2)                  88° 렌즈: f = 1,141 px
φ   = θ + atan((v − H/2) / f)              화면 v 행의 하향각 (θ = 마운트각)
      φ > 90° 이면 180° − φ (반대편으로 넘어감)
R   = h / sin φ                            사선 거리
d   = h / tan φ                            수평 거리
px  = max( (L·cos φ + foot·sin φ) / R ,  foot / R ) × f
```

| 자세 | L (세로 길이) | foot (위에서 본 폭·길이) |
|---|---:|---:|
| 서 있음 | 1.70 m | 0.81 m |
| 누움 | 0.30 m | 1.70 m |

- 0.81 m · 1.70 m 는 AI-Hub 라벨 6,000장 역산 → [[AI-Hub 182 조난자 수색]]
- 서 있는 사람은 **옆모습(L)** 이 보일수록 커진다 → 비스듬이 유리
- 누운 사람은 **위에서 볼 때(foot)** 가장 크다 → 수직이 유리
- 60° 는 **두 자세가 비슷한 크기**가 되는 지점 (30 m 중앙 51 · 56 px)

![[fig_마운트각별_사람px.svg]]

## 좌표 오차 — 마운트각이 낮을수록 커진다

```
∂d/∂φ = −h / sin²φ      (각도 오차)      Δd = Δz / tan φ   (지형 기복)
```

| 마운트각 | 25 m 합성 오차 |
|---:|---:|
| 90° | 3.1 m |
| **60°** | **4.7 m** |
| 45° | 6.8 m |
| 30° | 11.1 m |

지배 요인은 짐벌각이 아니라 **지형 기복** → [[NFR-V04 좌표 정확도]]

## 학습에 주는 영향

| | 수직 90° | 비스듬 60° |
|---|---|---|
| 화면 방향 | 위아래 없음 | **위 = 먼 쪽** |
| 회전 증강 | 180° 가능 | **±10°** 만 |
| 상하 반전 | 켠다 | **끈다** |
| 한 화면 안 크기 차 | 거의 없음 | 위아래 다르다 → 크기 분포를 넓게 |
| 가림 | 수관이 위를 덮는다 | 줄기·수관을 **옆에서** 더 많이 본다 |

> - 운영 환경 추론 속도는 재지 않았다. yolo11m @1280 은 11s @960 보다 무겁다 → NFR-V01 확인 필요

## 읽을 때 주의

> [!danger] `stage1_all` 과 비교하지 않는다
> 모델 · 시작 가중치 · 데이터 · 크롭 · 입력 크기 · 증강 · 배치 · **검증셋**이 모두 다르다. 학습 곡선의 val 점수는 노트북 수치와 다른 시험지다 → [[NOMAD 검증 배우 불일치]]
> `stage1_all` 을 새 val 크롭으로 다시 재는 실험은 **하지 않기로** 했다 (09-14 사용자 결정).

- optimizer auto 가 **MuSGD** 를 골랐다 → SGD 로 고정한 계획 `hyp_v2` 결과와 직접 비교하지 않는다
- 학습 중 val 점수는 `best.pt` 를 고르는 용도다. 판정은 도메인별 평가로 한다 → [[도메인별 평가]]

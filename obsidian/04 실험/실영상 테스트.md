## 실시간 탐지 테스트기 (09-19)

`drone_yolo/detect_live.py` — **영상 경로만 주면 창이 뜨고, 재생 중에 설정을 바꿔 가며** 본다. 정답이 없는 영상용이라 수치 판정은 `eval_domain.py` · `eval_perflight.py` 로 한다.

```bash
python detect_live.py --source "data/raw/okutama/Drone2/Noon/2.2.10.mp4"
python detect_live.py --source <영상> --weights weights/m1_11m_1280.pt weights/yolov8s_stage1_all.pt
```

| 바꿀 수 있는 것 | 방법 |
|---|---|
| 신뢰도 · IoU | 슬라이더 · `+` `-` (±0.05) |
| 입력 크기 640 / 960 / 1280 / 1600 / 1920 | 슬라이더 · `[` `]` |
| 최대 탐지 수 · 최소 박스 크기(px) · 프레임 건너뛰기 · 재생 속도 | 슬라이더 |
| 가중치 교체 (여러 개 올려 두고) | `m` |
| 추적기 ByteTrack 켜고 끄기 | `t` |

- 화면 위에 **ms/frame · fps · 박스 수 · 평균 신뢰도 · 박스 긴 변 중앙값(px)** 을 띄운다 → 사람이 몇 px 로 잡히는지 바로 보인다
- `space` 재생·정지 · `a` `d` 한 프레임 · `b` 박스 px 표시 · `l` 라벨 · `s` 화면 저장 · `r` 주석 영상 녹화 · `q` 종료
- `--weights` 를 비우면 `drone_yolo/weights` 와 노트북 `drone_dev/weights` 에서 자동으로 찾는다 (자세 트랙 가중치는 제외) → [[결정 - 자세 판별 제외]]
- 윈도우에서는 `detect_live.bat` 에 영상 파일을 끌어다 놓아도 된다
- 서버 학습 가중치(`m1_11m_1280.pt` · `m2_11m_1280_sard.pt` 등)는 git 밖이라 **서버에서 직접 받아** `drone_yolo/weights/` 에 둔다 → [[학과 서버]]

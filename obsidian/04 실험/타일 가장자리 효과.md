> [!summary] 타일 추론에서 **가장자리에 걸친 사람을 덜 찾는다**
> 도구 `eval_tile_edge.py` · 결과 `metrics/tile_edge_fov_11m_1280_all.csv`

## 왜 의심했나

학습 크롭 5,770개의 사람 위치를 세어 보니:

| 항목 | 값 |
|---|---|
| 가로 위치 5 % / 중앙 / 95 % | 0.21 / 0.50 / 0.78 |
| 가장자리 **100 px** 안에 있는 사람 | **1.8 %** |
| 가장자리 50 px 안 | 0.8 % |
| 가장자리 20 px 안 | 0.1 % |

크롭 위치 지터가 ±30 % 라 사람이 거의 항상 창 가운데 20~80 % 구간에 온다.
그런데 [[타일 추론]] 에서는 사람이 타일 **어디에나** 온다 → 학습/추론 불일치 가설.

> [!note] 저장된 크롭 기준이라는 단서
> 학습 중에는 `translate 0.15` 증강이 이미 이미지를 ±15 % 흔든다. 모델이 실제로 보는 분포는 위 표보다 넓다.
> 이 실험은 **그래도 남는 차이**를 잰 것이다.

## 방법

타일마다 그 안에 **온전히 들어온** 채점 대상 정답만 골라, 가장자리까지 거리 구간별로
**그 타일 자신의 예측**이 맞혔는지 본다. **NMS 로 합치기 전**이라 다른 타일이 구해 주는 효과가 빠진다.

## 결과 (fov_11m · conf 0.15)

**서 있는 사람 38 px**

| 가장자리까지 거리 | 정답 수 | 재현율 |
|---|---:|---:|
| 0~20 px | 481 | 0.2391 |
| 20~50 px | 784 | 0.2360 |
| 50~100 px | 1,144 | 0.2386 |
| 100~200 px | 2,408 | 0.2612 |
| **200 px 이상 (중앙)** | 2,954 | **0.3131** |

**누운 사람 128 px**

| 거리 | 정답 수 | 재현율 |
|---|---:|---:|
| 0~20 px | 245 | 0.6367 |
| 20~50 px | 300 | 0.6300 |
| 50~100 px | 533 | 0.6004 |
| 100~200 px | 1,037 | 0.6239 |
| 200 px 이상 | 869 | **0.6640** |

## 읽어낸 것

1. **작은 대상에서 −24.6 %** (중앙 0.3131 → 가장자리 0.236). 표본 481~2,954개로 충분하다
2. **경계가 100 px 근처다** — 0~100 px 구간이 0.236~0.239 로 평평하다가 100 px 을 넘으며 오른다.
   학습 크롭의 "가장자리 100 px 안 1.8 %" 와 **같은 경계**다
3. **큰 대상은 덜 민감하다** (누운 사람 −9.6 %). 일부가 잘려도 나머지로 알아본다
4. [[타일 추론]] 의 이득이 +8.3 % 에 그치고 오탐이 0.401 → 0.594 로 오른 것의 원인일 수 있다.
   겹침 50 % 라 가장자리 대상도 다른 타일에서는 중앙에 오지만, 그 타일에서 놓치면 기회가 준다

## 대응 — `translate` 0.15 → 0.30 (진행 중)

크롭을 다시 만들지 않는다 (109 GB 재생성에 몇 시간). 학습 중 위치 증강 폭만 키워 같은 효과를 얻는다.
`train_person.py` 에 `--translate` 옵션을 추가했다 (지금까지 0.15 고정이었다).

| 학습 | `e1_11m_translate30` |
|---|---|
| 바뀐 것 | translate 0.15 → **0.30** · close_mosaic 5 → **0** |
| 나머지 | fov_11m 과 동일 (11m · 1280 · batch 8 · 30에폭 · SGD lr0 0.01 · scale 0.3) |
| 시작 | 09-20 16:26 · 에폭당 25분 → 09-21 새벽 완주 예정 |

**판정 기준**

| | fov_11m | 성공 조건 |
|---|---:|---|
| 가장자리 0~100 px | 0.236~0.239 | 중앙(0.313)에 가까워진다 |
| 중앙 200+ px | 0.3131 | **유지된다** (떨어지면 translate 가 과한 것) |
| 가림 지형 39칸 | 기준선 | 전반 유지/개선 |

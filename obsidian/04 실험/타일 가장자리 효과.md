> [!summary] 타일 추론에서 **가장자리에 걸친 사람을 덜 찾는다**
> 도구 `eval_tile_edge.py` · 결과 `metrics/tile_edge_fov_11m_1280_all.csv`

## 왜 의심했나

학습 크롭 5,770개의 사람 위치를 세어 보니:

| 항목 | 값 |
|---|---|
| 정규화 가로 위치 5 백분위 / 중앙값 / 95 백분위 (0 = 왼쪽 끝, 1 = 오른쪽 끝) | 0.21 / 0.50 / 0.78 |
| 가장자리 **100 px** 안에 있는 사람 | **1.8 %** |
| 가장자리 50 px 안 | 0.8 % |
| 가장자리 20 px 안 | 0.1 % |

크롭 위치 지터가 ±30 % 라 사람이 거의 항상 창 가운데 20~80 % 구간에 온다.
그런데 [[타일 추론]] 에서는 사람이 타일 **어디에나** 온다 → 학습/추론 불일치 가설.

> [!note] 저장된 크롭 기준이라는 단서
> 학습 중에는 `translate 0.15` 증강이 이미 이미지를 ±15 % 흔든다. 모델이 실제로 보는 분포는 위 표보다 넓다.
> 이 실험은 **그래도 남는 차이**를 잰 것이다.

## 방법

타일마다 그 안에 **온전히 들어온** 채점 대상 정답만 골라, 가장자리까지 거리 구간별로
**그 타일 자신의 예측**이 맞혔는지 본다. **NMS 로 합치기 전**이라 다른 타일이 구해 주는 효과가 빠진다.

## 결과 — 재현율@conf 0.15 (fov_11m · IoU 0.5 · 타일 자신의 예측만 · NMS 전)

**서 있는 사람 38 px**

| 가장자리까지 거리 | 정답 수 | 재현율@0.15 |
|---|---:|---:|
| 0~20 px | 481 | 0.2391 |
| 20~50 px | 784 | 0.2360 |
| 50~100 px | 1,144 | 0.2386 |
| 100~200 px | 2,408 | 0.2612 |
| **200 px 이상 (중앙)** | 2,954 | **0.3131** |

**누운 사람 128 px**

| 가장자리까지 거리 | 정답 수 | 재현율@0.15 |
|---|---:|---:|
| 0~20 px | 245 | 0.6367 |
| 20~50 px | 300 | 0.6300 |
| 50~100 px | 533 | 0.6004 |
| 100~200 px | 1,037 | 0.6239 |
| 200 px 이상 | 869 | **0.6640** |

## 읽어낸 것

1. **작은 대상에서 −7.7 %p** — 중앙(200 px+) 재현율@0.15 **0.3131** → 가장자리(0~50 px) **0.2360** (상대 −24.6 %). 표본 481~2,954개로 충분하다
2. **경계가 100 px 근처다** — 0~100 px 구간이 0.236~0.239 로 평평하다가 100 px 을 넘으며 오른다.
   학습 크롭의 "가장자리 100 px 안 1.8 %" 와 **같은 경계**다
3. **큰 대상은 덜 민감하다** — 누운 128 px 은 0.6640 → 0.6004 로 **−6.4 %p** (상대 −9.6 %). 일부가 잘려도 나머지로 알아본다
4. [[타일 추론]] 의 이득이 **+2.9 %p**(상대 +8.3 %)에 그치고 음성 프레임 오탐이 0.401 → 0.594 **건/프레임**으로 오른 것의 원인일 수 있다.
   겹침 50 % 라 가장자리 대상도 다른 타일에서는 중앙에 오지만, 그 타일에서 놓치면 기회가 준다

## 대응 시도 — `translate` 0.15 → 0.30 → **실패** (09-21 종료)

크롭을 다시 만들지 않고(109 GB 재생성 회피) 학습 중 위치 증강 폭만 키워 같은 효과를 노렸다.
`train_person.py` 에 `--translate` 옵션을 추가했다 (그전까지 0.15 고정).

| 학습 | `e1_11m_translate30` |
|---|---|
| 바뀐 것 | translate 0.15 → **0.30** · close_mosaic 5 → **0** |
| 나머지 | fov_11m 과 동일 (11m · 1280 · batch 8 · 30에폭 · SGD lr0 0.01 · scale 0.3) |
| 경과 | **09-20 16:27 ~ 09-21 05:29 KST** · 30에폭 완주 · 26.1분/에폭 |
| best.pt | 18에폭 (fitness = val mAP50-95 **0.2427** vs 기준선 0.2401) |

### 결과 — 서 있는 38 px · 재현율@conf 0.15

| 가장자리까지 거리 | 정답 수 | 기준선 | translate 0.30 | 변화 |
|---|---:|---:|---:|---:|
| 0~20 px | 481 | 0.2391 | 0.2349 | −0.4 %p |
| 20~50 px | 784 | 0.2360 | 0.2003 | −3.6 %p |
| 50~100 px | 1,144 | 0.2386 | 0.2002 | −3.8 %p |
| 100~200 px | 2,408 | 0.2612 | 0.2101 | −5.1 %p |
| **200 px+ (중앙)** | 2,954 | **0.3131** | **0.2512** | **−6.2 %p** |
| **가중 평균** | 7,771 | **0.2737** | **0.2248** | **−4.9 %p (상대 −17.9 %)** |

**누운 128 px**: 가중 평균 0.6330 → 0.6394 (**+0.6 %p**) — 사실상 변화 없음

### 가림 지형 40칸으로도 확인 (`eval_fovbudget`)

평균 재현율@0.15 **0.4780 → 0.4483 (−3.0 %p · 상대 −6.2 %)**.
가장자리와 무관한 별도 시험셋에서도 떨어졌다 — **가장자리 문제가 아니라 모델 자체가 나빠진 것**이다.

> [!failure] 목표 지표는 개선됐는데 실패다
> 가장자리(0~20)/중앙(200+) 격차는 **−23.6 % → −6.5 %** 로 확실히 좁혀졌다.
> **그런데 중앙이 무너져서 좁혀진 것이다** — 중앙이 −6.2 %p 떨어져 가장자리 수준으로 내려앉았고,
> 가장자리 자체는 −0.4 %p 로 거의 그대로다.
>
> 미리 세워 둔 판정 기준의 두 번째 줄 **"중앙 200 px+ 는 유지된다 (떨어지면 translate 가 과한 것)"** 에 정확히 걸렸다.
> **기준을 먼저 적어 둔 덕분에 "격차가 줄었다"는 좋은 소식으로 오독하지 않았다.**

### 왜 그런가

평행이동을 ±384 px 로 키우면 38 px 대상이 화면 밖으로 잘리거나 모자이크 이웃과 겹치는 비율이 오른다.
작은 대상은 잘리면 남는 게 없어 유효 학습 신호가 준다.
**누운 128 px 이 멀쩡한 것**이 이 설명과 맞는다 — 큰 대상은 일부 잘려도 나머지로 배운다.

학습 곡선에도 징후가 있었다. val mAP50 최고가 0.4598 로 기준선 0.4779 보다 낮았는데,
그때는 "난도가 올라서"로 해석했다. 실제로는 **작은 대상을 덜 배운 것**이었다.

> [!note] 부수 소득 — 정점 이후 하락이 절반으로 줄었다
> 정점 → 최종 val mAP50 하락이 기준선 −5.2 %p(상대 −10.8 %) → **−2.4 %p(상대 −5.2 %)**.
> 다만 `translate 0.30` 과 `close_mosaic 0` 을 **같이 바꿔서** 어느 쪽 효과인지 분리되지 않는다.
> [[서버 L1 - yolo11l 1280]] 의 close_mosaic 증거를 보면 후자일 가능성이 높다.

## 결론 — 타일 겹침에 맡긴다

| 후보 | 비용 | 판단 |
|---|---|---|
| translate 0.20~0.25 재시도 | 13시간 | 0.30 에서 중앙 −6.2 %p 였으니 0.20 도 손해 가능 · 이득 상한은 가장자리 +7 %p |
| 크롭 생성 단계에서 위치 지터 확대 | 109 GB 재생성 · 수 시간 | 잘림 없이 가장자리 배치 가능하나 기대 이득 대비 비쌈 |
| **아무것도 안 한다** | 0 | **채택** — 4×(1280×720)은 겹침 50 % 라 한 타일에서 가장자리인 대상이 다른 타일에서는 중앙에 온다. NMS 합친 최종 성능은 이미 단일 1920 대비 **+2.9 %p** |

같은 13시간이면 **전처리 v3**(크기 분포 재설계 · 음성 비율 2.4 → 15 %)가 기대값이 크다 → [[4 전처리 - 크기 정규화와 지터]]

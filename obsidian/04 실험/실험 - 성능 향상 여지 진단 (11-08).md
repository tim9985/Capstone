## 4. AdaBN — 라벨 없이 현장 영상으로 BN 통계 맞추기 ❌

- 방법 (`adabn_probe.py`): v12_f91 의 BN 평균 · 분산을 대상 영상 (운용과 같은 타일) 으로 다시 계산 → 원래 통계와 섞음 (α = 현장 몫) · 평가셋을 시퀀스 반으로 — **A 로 맞추고 B 로 잼 · B 로 맞추고 A 로 잼** (맞춘 그림으로 재지 않음)

| AP50 (IoU 0.3 · 중심) | 원래 | α 1.0 (통계 교체) | α 0.5 (반반) |
|---|---|---|---|
| 비스듬 | 0.616 (0.841 · 0.864) | 0.591 (0.810 · 0.836) **−2.5** | 0.609 (0.839 · 0.863) −0.7 |
| 숲 | 0.640 (0.769 · 0.822) | 0.457 (0.543 · 0.582) **−18.3** | 0.563 (0.678 · 0.718) **−7.7** |

- 중심 일치로도 떨어짐 → 박스 습관이 아니라 진짜 손해 · 학습 데이터 BN 재계산 (`soup.py --bn` · 박스 넓어짐) 과 같은 방향 → **현장 적응은 BN 이 아니라 데이터 (D1)**

## 6. 그래서

1. **NFR-V03 판정 방식** — 공개 평가셋 AP50 은 정답 박스 습관이 섞임 → 실기체 C 장소 (우리 라벨 · 우리 습관) 를 주 판정 · 공개 셋은 AP50 + 중심 일치 함께 보고 (사용자 · 교수님과 상의)
2. **데이터 다양성** — FlyPose 가 쓴 출처 중 우리에게 없는 것 (Manipal-UAV · TinyPerson · VTSaR · SeaDronesSee) 라이선스 · 조건 확인 → 맞는 것만 v12 목록에 (반복 2 · 미리 정한 기준)
3. **비행 뒤 재분석** — v12 + FlyPose 합침 (같은 헛탐지에서 비스듬 +6.3 %p) · 실시간 수치와 따로 표기
4. **D1 실기체 재학습** 그대로 1순위 — 공개 데이터 위 손잡이 (증강 · 구조 · BN · 확인기) 는 다 막힘

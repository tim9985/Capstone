# 비전 파트 정리 — 교수님 최종발표 대비 미팅 (11-01)

> 비전 담당 정서인 · 수치 기준 11-01 · 최종발표 · 엔지니어링 페어 11-25 · 실기체 수치 동결 11-21

## 1. 한눈에

- **하는 일**: 드론 영상에서 사람을 찾고 → 같은 사람을 따라가고 → 누워서 오래 멈춘 사람을 위급 순서로 올리고 → 위치(위경도)와 상의 색을 관제 화면에 보냄
- **원칙**: 사람을 거르지 않고 **순위만** 매긴다 · 최종 판단은 운영자
- **지금 수준**
  - 실시간: 1080p 한 장 **20.6 ms** (기준 30 ms 이하 ✅)
  - 사람 찾기 (학습에 안 쓴 장소로만 평가): 한국 **1.00** ✅ · 숲 **0.66** · 비스듬 **0.62** (기준 0.80 — 숲 · 비스듬 미달)
  - 사람 없는 장면 헛탐지: 장당 **0.5건** (기준 1건 이하 ✅)
  - 위치 오차 (시뮬레이션): **0.3~0.6 m** (기준 10~15 m ✅)
- **공개된 기성 모델 13개와 비교**: 12개 평가셋 중 11개에서 우리 모델이 앞섬 → **11-04 정정**: 기성마다 최선 추론 (통째 · 창) 으로 다시 재면 AP 11셋 중 9셋 (LADD 짐 · Cyprus 비김) → [[실험 - 기성 모델 대 우리 모델 (데이터셋 12개 · 11-01)]] §4-3
- **남은 핵심**: 실기체(~11-06 도착)로 처음 재는 우리 카메라 · 우리 장소 성능

## 2. 비전이 하는 일 (5단계)

| 단계 | 하는 일 | 쓰는 기술 |
|---|---|---|
| ① 사람 찾기 | 1080p 한 장을 4조각으로 나눠 작은 사람까지 찾음 (누운 · 가려진 사람 포함) | YOLO11m 직접 학습 · TensorRT |
| ② 따라가기 | 같은 사람에게 같은 번호 · 드론 흔들림 보정 | BoT-SORT |
| ③ 위급도 | 박스 모양 (누움 · 앉음) + 드론 움직임을 뺀 「멈춘 시간」 → 긴급 · 높음 · 확인 · 보통 | 자체 규칙 |
| ④ 위치 | 사람 발끝 → 카메라 광선 → 지형과 만나는 점 → 위경도 | 지형 고도 (DEM) |
| ⑤ 인상착의 | 상의 색 12가지 · 「빨간 옷 입은 사람」 검색 순위 | SigLIP 2 (추가 학습 없음) |

## 3. 요구명세 대비 현재 성능

| 항목 | 기준 (요구명세 v1.7) | 현재 | 판정 |
|---|---|---|---|
| 한 장 처리 시간 | ≤ 30 ms | 20.6 ms (전 과정 38~51 ms · 초당 약 20장) | ✅ |
| 사람 찾기 정확도 (AP50) | ≥ 0.80 · 학습/평가 장소 분리 | 한국 1.00 · 숲 0.66 · 비스듬 0.62 | ⚠ 숲 · 비스듬 미달 |
| 헛탐지 (사람 없는 장면) | ≤ 1 건/장 | 0.17~0.55 | ✅ |
| 위치 오차 | 10~15 m | 0.3~0.6 m (시뮬레이션) | ✅ (실기체 미측정) |
| 누운 사람 가려내기 | — | AUROC 0.92 (찾은 사람 중 · 실제 드론 공개 영상) | 참고 |
| 상의 색 맞히기 | — | 6개 평가셋 평균 0.34 → 0.61 (규칙 → SigLIP 2) | 참고 |

- **AP 0.80 미달 설명**: 학습에 전혀 쓰지 않은 장소로만 잼 → 같은 데이터를 나눠 잰 논문 값 (WiSARD 0.89 · Okutama 0.72) 보다 낮게 나오는 게 정상 · 운용 크기 (사람 키 50~80 px) 재현율은 0.81~0.84 · 우리 조건과 가장 비슷한 외부 실사진 (UAV-SAR · 15 · 30 m · 45°) 은 **0.95**

## 4. 그동안 한 일 · 핵심 판단

- **데이터를 원본부터 다시 구성** (10-12 · v12): 공개 드론 데이터 10종 · 18,601장 · 확대 금지 · 평가 장소는 학습에서 뺌 → 숲 +4.8 %p · 작은 사람 재현율 0.26 → 0.55 · 헛탐지 3.2 → 0.5 건/장
- **헛탐지 기준 안에서 가장 낮은 문턱 (0.20)** — 수색에선 놓치는 것이 더 위험
- **자세는 「분류」 하지 않고 순위만**: 자세 분류기는 처음 보는 장소에서 0.97 → 0.09 로 무너짐
- **정직한 평가 규칙**: 학습 장소와 평가 장소 분리 · 같은 설정을 여러 번 학습한 평균끼리 비교 · 판정 기준은 실험 전에 기록
- **상의 색**: 손으로 만든 규칙 → 그림 · 글을 같이 배운 모델 (SigLIP 2) 로 교체 (worker 1.3) · 풀밭 위 「초록」 오인은 「잔디」 문장 비교로 줄임
- **기성 모델 비교** (11-01): 공개 가중치 13개 (데이터셋 하나로만 학습한 전용 모델 포함) 를 같은 방식으로 평가

## 6. 해 봤지만 효과 없던 것 (요약)

- 모델 키우기 (11m → 11l) · 다른 구조 (YOLO26 · 작은 물체용 손실) · 더 길게 학습 → 손해 또는 차이 없음
- 누운 사람 보강 (사진 3배 · 누운 사람 붙여넣기 · 회전 박스 수정) → 누움 개선 없고 헛탐지 증가
- 압축 화질 증강 학습 · 탐지 전 흐림 처리 → 독립 평가셋에서 손해
- ➜ 공개 데이터만으로 더 올리기는 한계 · **실기체 데이터가 다음 단계**

## 7. 남은 문제 · 한계

- 숲 가림 · 아주 작은 사람 (AP 0.66 · 0.62)
- **누운 사람**: 실제 드론 공개 영상에서 찾는 비율 약 0.6~0.7 · 학습 반복마다 ±8 %p 흔들림 → 실기체 촬영으로 판정
- 같은 사람이 후보 여러 개로 쪼개짐 (사람당 4~5개) — 운영자 화면에서 중복
- 상의 색: 비슷한 색 헷갈림 (검정 ↔ 남색 · 흰 ↔ 회색 · 빨강 ↔ 주황)
- 실시간 영상 압축 (H.264 4~8 Mbps) 에 약할 수 있음 (압축 시험에서 누운 사람 −10 %p)
- 밤 · 비 · 짙은 숲 아래는 범위 밖 (열화상 없음)

## 8. 최종발표까지 일정

| 기간 | 비전 할 일 |
|---|---|
| ~11-05 | 실기체 평가 도구 준비 (녹화 → 자동 채점) · 현장 적응 학습 연습 · 상의 색 worker 1.3 배포 |
| 11-06~12 | 실기체 도착 · 카메라 화각 실측 · 첫 비행 (빈 장면 헛탐지 · 16 · 20 m) → 1차 현장 적응 학습 |
| 11-13~19 | 본 촬영 (출연 2~4명 · 누운 사람 장면 먼저 · 옷 색 · 위치 실측) → 최종 모델 선택 |
| **11-21** | 수치 동결 |
| 11-25 | 최종발표 · 엔지니어링 페어 (포스터 · 시연 영상) |

- 실기체 판정 기준 (미리 정함): 누운 사람 재현율 **≥ 0.80** (16 · 20 m) · 헛탐지 ≤ 1 건/장

## 9. 교수님께 여쭐 것

1. **AP 0.80 미달 (숲 0.66 · 비스듬 0.62)** 을 발표에서 어떻게 보여 드리면 좋을지 — 「장소 분리 정직한 평가 + 운용 크기 0.8 이상 + 외부 실사진 0.95 + 실기체 수치」 로 설명해도 될지
2. **실기체 평가 장소 · 비행 허가** (교내 · 인근) 와 출연자 촬영 동의 절차
3. 기성 모델 비교 · 「해 봤지만 안 된 것」 을 발표에 어느 정도 넣을지
4. 실기체 평가셋 규모 (라벨 몇 백 장 수준) 가 충분한지

## 용어

- **AP50**: 사람을 얼마나 빠짐없이 · 정확히 찾는지 한 숫자로 (1 이 만점)
- **재현율**: 실제 사람 중 찾은 비율 · **헛탐지**: 사람이 아닌데 사람이라고 한 것
- **장소 분리 평가**: 학습에 쓴 장소의 사진은 평가에 쓰지 않음
- **AUROC**: 누운 사람을 위로 올리는 순위 능력 (0.5 = 우연 · 1 = 완벽)

> [!summary] 3인 팀 · 금오공대 캡스톤디자인

| 이름 | 역할 | 맡은 것 |
|---|---|---|
| **이시원** | 팀장 · 관제 | 관제 웹, MissionMap, 상황 지도, [[관제 뷰어 프로토타입]] |
| **서성훈** | 비행 제어 | 기체 · FC · 영상 링크 · 게이트웨이 |
| **정서인** | 비전 | 탐지 모델, 상의 색상 비교, 좌표 변환, 추적 (자세 판별은 제외 → [[결정 - 자세 판별 제외]]) |

## 비전이 넘겨주는 것

```
[ { track_id, class(정상/쓰러짐), confidence,
    lon, lat, uncertainty(a, b, θ), capturedAt, snapshot } ]
```

- 지도 갱신·재계획은 **MissionMap(이시원)** 이 맡는다. 비전은 좌표까지.
- 요구명세서는 비전 파트를 따로 써서 동료가 합친다 → [[요구명세서]]

## NOMAD — rclone

```bash
# 서버엔 브라우저가 없다 → 노트북에서 토큰을 받아 서버 프롬프트에만 붙인다
rclone config                  # n → gdrive → drive → 스코프 1 → auto config 'n'
#   노트북: rclone authorize "drive"

export RCLONE_DRIVE_ROOT_FOLDER_ID=1zRiOzedR-PzO1bps5I1vb6jtVoQHFWzg
rclone lsd gdrive:             # annotations / images / labels / videos

rclone copy gdrive:annotations ./NOMAD -P
rclone copy gdrive:labels ./NOMAD/labels -P \
  --transfers 32 --checkers 32 --drive-pacer-min-sleep 10ms --drive-pacer-burst 200
rclone copy gdrive:images ./NOMAD/images -P \
  --transfers 16 --checkers 32 --drive-pacer-min-sleep 10ms --drive-pacer-burst 200
```

> [!warning] 토큰은 채팅·문서에 남기지 않는다

50·70 m 원본(학습 배우 60명)은 `download_nomad_far.sh` — 서버에 30 m 가 있는 배우만 필터로 골라 labels → images 순서로 받는다 (09-14 · a50·a70 각 5,165장 · 71 GB · 약 6시간).

```bash
cd ~/JupyterLAB/Capstone/drone_yolo && setsid nohup ./download_nomad_far.sh > logs/nomad_far_dl.log 2>&1 < /dev/null &
```

## SARD — Roboflow

Roboflow 키가 필요하다. **키는 파일로만** 넘긴다 (`~/.config/roboflow/api_key` · 권한 600) — 채팅 · 문서 · 명령줄에 쓰지 않는다.

```bash
# 별도 터미널에서 키 파일 만들기 (입력이 화면 · 셸 기록에 안 남는다)
mkdir -p ~/.config/roboflow && (umask 077; read -rsp 'Roboflow key: ' K; echo; printf '%s' "$K" > ~/.config/roboflow/api_key)
cd ~/JupyterLAB/Capstone/drone_yolo && setsid nohup ./download_sard.sh > logs/sard_dl.log 2>&1 < /dev/null &
```

- `download_sard.sh` — NOMAD 받기가 돌고 있으면 끝나길 기다린 뒤 v1 yolov8 zip → `data/raw/sard2/search-and-rescue-2` · 장수 검사 · 해상도 기록 · `data/raw/sard_dl.done`
- 키는 인증 헤더로 보내 명령줄 · `ps` · 로그에 드러나지 않는다
- 09-14 확보: 1,386 · 396 · 198장 · 해상도 전부 **1920×1080** (축소 재배포 아님)

> [!warning] SARD test 는 train 과 연속 프레임이다
> Roboflow 가 프레임 단위 무작위로 나눴다 → test 87 % · valid 91 % 가 train 프레임과 번호 차이 1 이내. 점수가 부풀려진다 → 번호 구간 단위로 다시 나눈 뒤 쓴다

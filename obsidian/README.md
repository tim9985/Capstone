# 비전 파트 지식 볼트 (Obsidian)

비전 파트의 프로젝트 조건 · 데이터셋 · 모델 · 실험 · 결정 · 이슈 · 성능 요구사항 · 서버 학습 계획 · 타임라인을
서로 링크된 노트 118개로 정리한 [Obsidian](https://obsidian.md) 볼트.

## 여는 법

1. 이 저장소를 클론한다
2. Obsidian → **보관함 열기** → `obsidian` 폴더 선택
3. `00 홈` 노트에서 시작한다

| 볼 것 | 위치 |
|---|---|
| **전체 목차 · 현재 상태** | `00 홈.md` |
| **시간순 기록** | `09 기록/타임라인.md` |
| **실험 18건 색인** | `04 실험/_실험 색인.md` |
| **개념 20건 색인** | `07 개념/_개념 색인.md` |
| 남은 일 | `09 기록/다음 할 일.md` |
| 성능 요구사항 풀이 | `10 성능 요구사항/성능 요구사항 한눈에.md` |
| 서버 학습 계획 (S0~S8) | `11 서버 학습 계획/0 서버 학습 계획 한눈에.md` |
| 하드웨어 확정안 | `05 결정/결정 - 하드웨어 예산안 합의 v4.md` |
| 한 장 지도 · 모델 계보도 | `프로젝트 지도.canvas` · `가중치 계보.canvas` |
| 실험 비교표 | `04 실험/실험 비교.base` (Obsidian 1.9 이상) |
| 노트 연결 | 그래프 뷰 — 폴더별로 색이 다르다 |

## 폴더 구조

```
00 홈.md              주제별 허브 — 여기서 시작

02 데이터셋/          NOMAD · WiSARD · SARD · AI-Hub · Okutama
```

GitHub 에서도 마크다운으로 읽을 수 있지만 `[[링크]]` · 캔버스 · 비교표는 Obsidian 에서만 동작한다.

## 갱신 (2026-09-14 부터)

노트북 · 서버 모두 **저장소 안의 `obsidian` 을 직접** Obsidian 으로 연다.

```bash
git pull                                            # 편집 전
# … Obsidian 에서 편집 …
git add obsidian && git commit -m "볼트: <무엇을>" && git push
```

- 같은 노트를 두 곳에서 동시에 고치지 않는다. 서버 세션은 주로 `08 서버` · 서버 실험 노트 · `09 기록/타임라인` 을 고친다
- 저장소 밖 볼트를 복사해 넣던 `sync_vault.py` 는 없앴다 (서버에서 고친 노트를 덮어썼다)
- `.obsidian/workspace*.json`(개인 화면 상태) · `.trash/` 는 올리지 않는다

## 주의

- **공개 저장소다** — 팀 내부 배포 주소 · 개인 연락처를 노트에 적지 않는다 (`sync_vault.py` 가 하던 가리기는 이제 없다)
- 확정 문서는 **1. 주제제안서 · 2. 요구사항명세서 최신판** — 노트와 어긋나면 이 둘이 우선한다
- 수치의 원본은 [`drone_yolo/metrics/*.csv`](../drone_yolo/metrics/) 와 `drone_yolo/` 문서다. 이 볼트는 요약이다
- 연구용 데이터셋(NOMAD · WiSARD · Okutama)의 이미지는 들어 있지 않다
